# v0.4.3 하수인 아트

CJ가 제공한 `all-minions-v0.4.3` 패키지의 하수인 20종 원본을 보존한다.
2026-09-07 CJ 지시로 GitHub 등록 및 말판 아이콘 제작을 진행한다.
이 디렉터리의 존재는 게임의 이미지 로딩 구현이나 배포 방식 승인을 뜻하지 않는다.
제품 구현은 최종 분석 보고 후 별도 CJ 구현 OK를 기다린다.

## 파일 구성

각 `속성_아키타입` 폴더의 제공 원본:

| 파일 | 용도 | 크기 |
|---|---|---|
| `portrait.png` | 설명창 원본 보존 | 512×512 |
| `portrait.webp` | 설명창 배포 후보 | 512×512 |
| `battle-grid.png` | 전투 도트 작업 그리드 보존 | 64×64 |
| `battle.png` | 전투 도트 배포 후보 | 128×128 |

원본은 20종 × 4파일 = 80파일, 총 7,488,176바이트다.
원본 패키지와 반입 파일의 SHA-256을 대조했다.
[원본 매니페스트](../../../docs/art/minions-v0.4.3/source-manifest.csv)에 경로·크기·해시를 기록한다.
`battle-grid.png`는 제작 원본이며 런타임에서 로드하는 파일이 아니다.

32×32 말판 `icon.png`는 별도 제작·검수 대상이다.
로스터 ID·이름·폴더 대응 및 납품 기준은
[외형 규격](../../../docs/minion-visual-spec-v0.4.3.md)을 따른다.
왕·동료·폭탄·함정·원소 기호는 기존 메모 이모지를 재사용한다.

## 자산 조건

이 디렉터리의 원본 및 파생 아트는 Apache-2.0 적용 대상이 아니다.
[ASSET-LICENSE.md](../../../ASSET-LICENSE.md)의 자산 조건을 따른다.
원본 작성 도구·프롬프트·레이어 파일의 출처는 제공 패키지에서 확인되지 않았으며,
파일 수령 사실을 권리 관계나 상업적 독창성의 검증으로 간주하지 않는다.
