# Digit Dual PVP 릴레이 서버

내부망(LAN) 전용 1:1 자동 매칭·릴레이 서버 + 데모 클라이언트(`../demo`) 정적 서빙.
서버는 게임 내용을 해석하지 않는 비권위 릴레이이며, 클라이언트는 시드 락스텝으로 동기화한다.

## 실행
- Windows: `서버시작.bat` 더블클릭 (최초 실행 시 의존성 자동 설치)
- 수동: `npm install` 후 `npm start`

접속: 브라우저에서 `http://localhost:8080` (상대는 `http://<서버IP>:8080`).
기동 시 콘솔에 내부망 접속 주소가 출력된다. 사설 IP 대역만 허용(내부망 전용).

## 테스트
`npm test` — 매칭 / 양방향 릴레이 / 이탈 알림 / 대기 슬롯 정리 자동 검증
