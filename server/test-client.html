PvP 테스트 클라이언트

대기 중 — 주소와 접속 코드를 입력하고 [접속]을 누르세요.

서버 콘솔에 접속 주소와 접속 코드가 서로 다른 줄로 출력됩니다(코드는 그 터미널에 운영자 전달용으로 한 번 표시됩니다). 코드는 WebSocket 업그레이드의 Sec-WebSocket-Protocol 헤더로만 전송되며, 이 페이지는 코드를 URL·쿼리·쿠키·브라우저 저장소·로그에 기록하지 않습니다. 다만 평문 ws:// 링크에서는 그 헤더도 평문이라 같은 망의 관찰자에게는 기밀이 아닙니다 — 헤더를 쓰는 목적은 도청 방지가 아니라 주소창·방문 기록·프록시 로그에 코드가 남지 않게 하는 것입니다. 서버가 다시 시작되면 코드도 새로 발급됩니다.

⚠️ 이 페이지를 html 파일로 직접 연 상태(file://)입니다. 서버는 file:// 페이지의 Origin(null)을 거부하므로 접속되지 않습니다. 이 파일을 서버가 서빙하는 폴더(demo/)에 복사한 뒤 http://127.0.0.1:8080/test-client.html(또는 http://<서버 IP>:8080/test-client.html)로 여세요.
