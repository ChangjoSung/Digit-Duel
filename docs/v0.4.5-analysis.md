## 2. CJ 결정이 필요한 두 경계

### A. 턴 버튼 제거와 선택 전투

현재는 주 행동을 마친 뒤 선택 가능한 전투가 하나라도 있으면 자동 종료를 보류한다. 이 상태에서 버튼만 삭제하면 “싸우지 않고 끝내기”가 불가능하다. 주 행동 이전에도 사용 가능한 행동이 있으면 자동 생략하지 않는다.

- **권고 A:** 평소 버튼은 없애고 선택 전투가 남았을 때만 “싸우지 않고 종료”를 표시한다. 기존 전투 선택권을 유지하지만 버튼 완전 삭제에는 예외가 생긴다.
- **대안 B:** 두 버튼을 완전히 없애고 주 행동·강제 접촉 처리가 끝나면 자동 종료한다. 선택 전투는 주 행동 전만 가능해진다.
- **대안 C:** 선택 전투를 폐지하고 신규 접촉 전투만 유지한다. 가장 큰 게임 규칙 변화다.
- 공통 보완 권고: 만피 말에도 회복 자세 지정을 허용해 “움직이지 않고 기다리기” 수단으로 쓴다. 현재는 만피 말에 새 회복 지정을 할 수 없다. 모든 유효 주 행동이 없으면 자동 생략한다.

Venus는 A, Mars는 B에 가까운 자동 종료안을 권고했다. 서로 다른 권고이므로 PD가 확정으로 기록하지 않았다. CJ에게 선택을 요청했다.

### B. 함정의 강제 밀기·재배치

새 원문은 폭탄→함정에도 “무조건 상대 말과 내 말 모두” 밀기를 요구한다. 기존 안내의 “함정 고정”과 경계를 정해야 한다.

- **PD 권고:** 최신 원문대로 함정도 강제 밀기·재배치를 허용하되 스스로 이동하는 행동은 계속 금지한다. 튜토리얼은 “스스로 움직일 수 없어요”로 고친다.
- **대안:** 함정은 고정하고 폭탄만 후퇴한다. Venus·Mars가 기존 규칙 보존을 위해 제시한 안이며 새 양측 밀기 지시의 예외가 된다.
- 어느 안이든 강제로 밀린 말을 “스스로 이동했으니 함정이 아니다”라고 AI가 추론하면 안 된다.

## 3. 함께 검토할 세부 계약안

다음은 구현 전에 CJ에게 제시하는 **권고·추론**이다.

1. 밀기 목적 칸이 보드 밖이거나 점유돼 있으면 해당 말은 제자리, 다른 말은 가능하면 한 칸 이동한다. 밀기 후 두 말이 여전히 붙어 있거나 다른 적과 붙게 된다면 재배치한다. 왕이 실제 밀려 상대 끝줄에 도달하면 원문대로 승리를 먼저 확정하고 후속 재배치를 중단한다.
2. 재배치는 자기 진영 → 자기 숲 → 중앙 광장 순서로 빈 칸·적 비인접 조건을 찾는다. 두 말의 출발 칸을 함께 비운 가상 상태에서 **두 목적지 조합**을 검토해 단순 선착순 배치로 둘째 말의 자리를 막지 않는다. 영역 우선순위, 원위치 거리, 자기 진영 방향 행, 열 순으로 동률을 해소하는 고정 규칙을 사용하고 난수를 소비하지 않는다.
3. 원문의 “상대 말을 피해서 배치”를 만족하려면 규칙 엔진은 숨은 적까지 고려해야 한다. AI 의사결정에는 숨은 위치를 제공하지 않으며, 후보·제외 사유·숨은 말 좌표는 UI/로그에 노출하지 않는다. **결과 위치에서 간접 추론할 가능성은 남는다.** Venus의 누설이 제한적이라는 평가와 Mars의 간접 누설 경고를 함께 보존한다. 가시 적만 피하는 대안은 원문의 비접촉 보장을 만족하지 않는다.
4. 모든 영역에서 안전한 두 목적지를 찾지 못할 때는 추가 제거·승패를 임의로 만들지 않고 제자리 또는 가능한 밀기 결과를 유지하고 해당 접촉을 한 번 처리한 것으로 종료하는 안을 권고한다. “항상 재배치로 분리”의 예외이므로 **CJ 확인 필요**다.
5. 도망 교환은 기존 후방 후보·생략 가능성을 유지하고, 교환하면 전선으로 들어온 말↔전투 상대를 민다. 교환을 생략하거나 후방 후보가 없으면 도망친 말↔상대를 민다. 교환·밀기·재배치 자체로 추가 강제 전투·탐색 흔적을 만들지 않는 안을 권고한다.
6. 온라인에서는 방어자의 도망 교환도 방어자 소유 입력으로 처리해야 한다. 현재 보드 cell 액션을 그대로 쓰면 S.current와 소유자가 달라 클릭이 거부된다. 선택 소유자·취소/생략·대기·입력 잠금·양측 동일 결과를 명시적으로 검증해야 한다.
7. 전투 횟수·회복 자세 해제·왕 끝줄 승리 우선순위·텔레포트 취소는 보존한다. AI의 텔레포트 반복 및 VIP끼리의 대리 출전 평가 변경을 검증하되 새 밸런스 수치를 임의로 도입하지 않는다.
