## 0. 한 장 요약

CJ 지시의 핵심은 **"턴 행동 사이에 플레이어 입력이 불가능한 연출 구간을 넣어 진행을 또렷하게 만들고, 행동을 건너뛰는 사고를 없앤다"**이다. 이 문서는 그 지시를 다음 8개 계약으로 나눈다.

## 3. 공통 원칙 — 연출 잠금과 결정론

### 3.1 규칙과 연출의 분리 [권고 — 구현 필수 원칙]
1. **규칙 상태(`S`) 전이는 지금처럼 동기·즉시.** `doMove → applyForced → initBattle → startRounds`, `execSlot → nextPhase`, `finishBattle → afterBattle` 등 기존 호출 사슬과 `rand()` 소비 순서를 바꾸지 않는다.
2. **연출은 표시 계층만 바꾼다.** 배너 오버레이, 입력 잠금, 표시 유지(hold: 이미 제거된 말을 폭발 연출이 끝날 때까지 그리기), 모달 내용 지연 표시, `dispHp`형 표시값.
3. **UI 타이머는 규칙 함수를 호출하지 않는다.** 예외 두 가지만 허용: (a) 자동 턴 종료 — 행동자 클라이언트가 연출 idle 후 `endTurn` **입력 액션**을 발생(4.6), (b) AI 스케줄 — 기존 `aiSchedule/aiScheduleBattle`이 idle 콜백에서 실행(6.3).
4. **온라인 수신 프레임은 절대 버리지 않는다.** 잠금 중에는 큐에 보관하고 idle에 적용한다(현행 `netReady`의 `!MSGPLAYING` 조건을 `!fxLocked()`로 확장). 잠금에는 반드시 하드 데드라인이 있어 큐가 영구히 막히지 않는다.

### 3.2 입력 잠금 — 규칙·검수 기준 [채택] (구현 세부는 Mars 설계)
- **불변식 1 — 토큰 보호**: 잠금·지연 표시 콜백은 발급 토큰(게임 식별·모달 seq 포함)을 들고 있다가 불일치하면 DOM·`S`를 건드리지 않는다(#94 메모 토큰 방식). 이전 게임·닫힌 모달·끝난 전투의 타이머는 무효.
- **불변식 2 — 하드 데드라인**: 모든 잠금은 선언 시간 + 1초 안에 반드시 풀린다(워치독). 새 게임 시작·경기 종료·phase 변경에서는 즉시 전부 해제. 모달 닫힘(`close()`)과 연출의 경합 처리 순서는 Mars 설계 사항이며, 검수 기준은 "잠금이 데드라인 안에 풀리고 규칙 상태가 바뀌지 않는다"뿐이다.
- 잠금 중 차단되는 입력: 보드 셀 클릭(`onCell`), 턴바 버튼, 전투 커맨드·아이템·볼·도망 버튼, 동기 모달 버튼(표시 자체를 지연). 기권 버튼은 잠금 중에도 허용 [권고].
- 잠금 중에도 허용: **로컬 메모 피커(#94)** — 단, 배너 오버레이가 화면을 덮는 동안(2초)은 차단. 표시 유지(hold)만 있는 동안은 메모 허용. 튜토리얼 다시 보기·로그 스크롤·설정은 항상 허용.
- 모달 소유권: 동기 모달의 seq·소유자 결정은 종전대로 `modal()` 호출 시점(동기). 잠금 중에는 **내용 표시만** 지연한다.

### 3.3 모드별 시간 [권고]

## 4. 보드 턴 흐름

턴 순서 [결정]: ① 턴 시작 배너 → ② 주 행동(이동·탐색·회복·텔레포트·생략) → ③ 접촉 처리(배너 → 상황 문구 → 해결/전투) → ④ 추가 접촉(전투 최대 2회) → ⑤ 턴 종료(자동 또는 버튼). GDD-13 4.3 순서와 같고, 회복이 추가되며 종료가 자동화된다.

### 4.1 턴 시작 배너 [결정]
- 트리거: `startTurn` 직후(핫시트는 `handoff` 확인 뒤). 화면 중앙 오버레이, `turnBanner` 동안 입력 잠금.
- 문구 [결정]: 제목 **"나의 턴!"**, 부제 *"말 이동 / 수풀 탐색 / 말 회복 행동 중 하나를 실행하세요!"* 상대 턴(온라인 비행동자·PVE AI 턴)은 **"상대 턴!"** + *"상대가 행동을 선택하고 있습니다"* [권고 부제].
- 핫시트: 기기를 받은 현재 플레이어 시점이므로 항상 "나의 턴!". sim: 없음.
- 기존 "— P1 턴 N —" 토스트·로그는 유지(로그 원본). 튜토리얼 힌트는 배너 **뒤**에 표시 [권고].
- **버닝 타임 배너 [결정 CJ 추가 / 2초 채택]**: 65턴 진입(`startTurn`에서 `btReached`가 처음 true가 되는 시점) 시 **"버닝타임입니다! 2칸씩 이동 가능합니다"** 배너를 `turnBanner`(2초) 동안 먼저 표시한 뒤 "나의 턴!/상대 턴!" 배너를 잇는다. 경기당 1회, 양측 화면 같은 순서(버닝 타임 → 턴), 입력 잠금·토큰 보호는 3.2. 배너는 표시 전용이며 송신·`rand()`·규칙 변경 없음(기존 `btReached` 지표·로그·토스트는 유지). 적진·적 숲 1칸 예외와 함정 고정 규칙은 바뀌지 않는다.
- 온라인: 양쪽이 각자 `startTurn`을 적용한 시점에 로컬 타이머로 표시. 배너 종료 시각은 동기화하지 않는다(3.1-4).

### 4.2 주 행동 — 말 회복 [결정 — CJ 최종 2026-09-08]

#### 4.2.1 CJ 확정 규칙 [결정]
- 주 행동으로 **자기 말 하나를 회복 지정**한다. 지정하면 그 턴의 주 행동은 끝난다.
- 지정된 말은 **재지정 없이 자동으로 계속 회복**한다(자세 지속형). 회복은 **지정한 이번 턴부터** 시작한다.
- 양: "나 한 번·상대 한 번이 지나야 10%" → 현재 턴 개념(나 1턴·상대 1턴)에서는 **개별 플레이어 턴마다 최대 HP 5%**. 소유자 턴·상대 턴 양쪽 모두 틱한다.
- 그 말의 **이동 / 수풀 탐색 / 전투**가 일어나면 회복이 풀리고 이펙트·효과가 제거된다.
- 말 주위 회복 이펙트(아트)로 회복 중임을 표시하고, HP 숫자는 틱마다 갱신된다.

#### 4.2.2 틱 경계와 중복 방지 [채택 — PD 권고 채택]
| 항목 | 계약 |
|---|---|
| 틱 시점 | **전역 플레이어 턴 종료(`endTurn`) 한 곳**에서, 그 시점에 회복 자세인 **양 플레이어의 모든 말**에 각 +`round(maxHp × 0.05)`, 상한 `maxHp`. `S.turn`가 증가하기 직전에 1회. 같은 `turn`에 두 번 틱하지 않도록 `S.healTickTurn` 가드 |
| "이번 턴부터" 충족 | 지정한 플레이어의 그 턴 종료 시 첫 틱(+5%). 다음 상대 턴 종료 시 +5% → 한 쌍이 지나면 10% |
| 즉시 틱 금지 | 지정 시점에 별도 즉시 회복 없음(턴 종료 틱과 이중 적용 방지) |
| 틱 전 해제 | 지정 후 같은 턴에 그 말이 전투(선택 전투·강제 전투·폭탄·함정·밀어내기 포함)에 들어가면 자세가 먼저 풀려 그 턴에는 틱이 없다. 해제는 항상 틱보다 먼저 판정된다 |
| 순서 | `endTurn` 안: 강제 전투 잔여 확인 → `immobile` 감소 → 지표 → **회복 틱** → `turn++` → 교대. AI·온라인 모두 같은 코드 경로 |

### 4.4 폭탄·함정 해결 [결정 — #106]

#### 4.4.1 연출 공통
- **폭발**: 상황 문구 뒤 폭발 이펙트를 해당 칸(들)에 `explosion` 동안 표시, 입력 잠금. 규칙은 현행처럼 즉시 적용(`alive=false`, 지표, `checkWipe`, `afterBattle`), **표시만 유지(hold)** — 제거된 말은 폭발이 끝날 때 사라진다. 이펙트 아트는 [Art] Earth 범위, 없으면 CSS 플래시·흔들림 폴백 [권고].
- **함정**: 상황 문구 뒤 `trapFx` 동안 함정 칸 강조·잠금. 규칙 변경 [결정 CJ 최종]:
  - 함정에 걸린 말 `revealed = true` · 함정 `revealed = true`(제거됨, 종료 리빌·로그 정합) · 걸린 말 `immobile = 2` 유지.
  - 로그 "정체 비공개 유지" 삭제 → "🪤 함정 발동! [말 이름] 정체 공개 · 2턴 이동 불가".

- 폭탄·함정 접촉도 전투 1회 계산(현행 유지). 관련 말의 회복 자세 해제(4.2.3).

### 4.5 추가 접촉 (2회째 전투) [결정]
- 규칙 불변: 첫 전투에서 이동한 말이 승리·생존했을 때만 두 번째, 상대는 최초 이동 종료 시 인접했던 적 중 선택(`contactSet`). 텔레포트 둘째 말은 독립 queue(`forcedQueue`).
- 연출: 첫 전투 종료 → 결과 배너 → 보드 복귀 → (둘째 강제 대상이 승격되면) 배너 **"⚠️ 상대 말 추가 접촉!"** + 상황 1/2 동일 흐름. 선택 전투(강제 아님)는 배너 없이 대상 클릭 → 상황 문구 → 해결 [권고].
- 전투 횟수 소진으로 강제 면제되는 경우 현행 로그·토스트 유지.

### 4.6 턴 종료 자동화 [결정 원칙 / H5 조건]
- **자동 종료 조건(모두 만족)** [권고]: `S.phase==="play"` · `!S.battle` · 오버레이·동기 모달 없음 · `!S.teleport`(텔레포트 선택 중 아님) · `forcedTargets` 비고 `forcedQueue` 비어 있음 · `mainUsed` · **자기 말 중 `canBattle` 가능한 가시 인접 적이 하나도 없음**(현행 `battleRefusals` 판정과 같은 술어) · 연출 idle.
- 주 행동 전 특례 [권고]: 이동·탐색·텔레포트·회복 어느 것도 불가능한 말뿐이면(전원 `immobile`, 흔적 없음, 텔레포트 불가, 회복 대상 없음) 토스트 "가능한 주 행동이 없습니다" 후 `skipMain`을 자동 적용하고 위 조건을 재평가.
- 발화 주체: **행동자 클라이언트만** — PVE 사람 턴은 로컬, 핫시트는 현재 플레이어, 온라인은 `S.current===NET.me`인 쪽이 `netAction({t:"endTurn"})`을 보낸다. 수신 측은 절대 스스로 endTurn 하지 않는다(중복 적용 방지). AI는 현행 `aiStep`의 `endTurn` 그대로.
- 타이밍: 조건 충족 후 `autoEndGrace`(1초) 뒤. 그 사이 사용자 입력(기권 등)이 들어오면 재평가.
- 버튼: **"턴 종료"·"주 행동 생략" 버튼은 유지**(선택 전투가 남은 경우, 또는 회복 대신 즉시 넘기고 싶은 경우). 강제 대상이 남으면 비활성(현행).
- 지표: 자동 종료는 `canBattle` 대상이 없을 때만 일어나므로 `battleRefusals`에 영향 없음. 자동/수동 구분 카운터 `autoEnds` 추가 [권고].
- 온라인 결정론: endTurn은 여전히 액션 프레임으로 전달되므로 양측 `S`는 동일. 자동 발화 시각은 로컬이며 동기화하지 않는다.

## 5. 전투 흐름

### 5.1 진입 [결정]
1. 상황 문구 "배틀을 시작합니다." (4.3) → 동료·왕이면 현행 비공개 출전 선택 모달(동기 모달, 소유자만 조작) → "출전 공개" (왕이 걸린 전투는 "👑 왕이 걸린 전투!" 부제, GDD 4.9) [권고].
2. 전투 화면 열림 → 중앙 **3 → 2 → 1** 각 `countStep` → **"배틀 시작!"** 1초. 입력 잠금. 규칙상 `startRounds`는 이미 완료되어 있다(표시만 지연).
3. 라운드 1 시작 → 5.2.

### 5.2 라운드·행동 배너 [결정]
- 배너 단위는 **행동(phase)** 이다: 라운드마다 두 번(선공·후공), 최대 12번. 문구 "나의 턴!/상대 턴!"(PVE·온라인), 핫시트 "P1 턴!/P2 턴!". 부제 "Round r / 6" [권고].
- `roundBanner` 동안 잠금 → 해제 후 4카테고리 메뉴 활성(사람) / AI는 idle 후 `aiDelay`.
- 선후공은 현행 `actorOfPhase`(감전 반전 포함) 그대로.

### 5.3 4카테고리 UI [결정] — 싸우기 / 가방 / 포획 / 도망가기
| 카테고리 | 열면 | 규칙 매핑(불변) |
|---|---|---|
| ⚔️ 싸우기 | 기술 4슬롯(이름·위력 범위·쿨) + 전 슬롯 쿨일 때만 "기본 공격" + ← 뒤로 | `__act(i)` / `__act('basic')` |
| 🎒 가방 | 아이템 목록 + ← 뒤로. 라운드당 1·전투당 2·연속 동일 불가 규칙 그대로 | `__useItem(i)` — **보너스 행동**: 사용 연출 후 같은 행동자의 메뉴로 복귀(GDD 4.6) |
| 🔴 포획 | 조건·성공률·볼 수 표시 + "던지기" 확인 + ← 뒤로. 조건 미충족은 사유 텍스트로 비활성 | `__throwBall()` — 하수인·HP 30% 미만·볼·예비 슬롯 빔·라운드당 1회 |

- 하위 메뉴 이동은 **로컬**(온라인 송신 없음). 송신되는 것은 최종 시맨틱 액션뿐(현행). 상대 화면은 현행대로 "상대 아이템 비공개".
- 왕·동료 본체(기술 없음): 싸우기 = 기본 공격 1개. 레거시 `skillAtk` 경로는 테스트 호환용으로 유지하되 UI 노출 없음(현행).
- 자기 기술 공개 표시(`revealedSkills`·`?공격기`)는 현행.
- 화면 구성: CJ 참조 이미지(포켓몬식) — 상단 상대 패널, 중앙 스테이지(토큰 128), 하단 내 패널, 그 아래 4카테고리. 세부 레이아웃은 Mars 구현 선택, 아트는 Earth.

### 5.4 행동별 연출 타임라인 [결정] — 규칙은 현행 `bmsg` 큐, 재생만 그룹화
| 행동 | 연출 순서 (각 구간 입력 잠금) | 큐 매핑 [권고] |
|---|---|---|
| 싸우기(피해) | 기술 연출 `skillFx` → 피 깎임 `damageFx` | 그룹1 = "X의 기술!"(속성 플래시·시그니처 점멸) / 그룹2 = "N 피해! (흡수) 유효" + HP바 감소 + 피해 팝 + 상태 부여 메시지. 후속 메시지(쿨 감소·약화 해제 등)는 그룹2에 포함 |
| 싸우기(보조기) | 기술 연출 → 효과 연출 `damageFx` | 그룹2 = 회복·보호막·집중·정화 메시지 + HP/방어막 바 갱신 |
| 가방 | 아이템 사용 `itemFx` → 같은 행동자 메뉴 복귀(배너 없음) | 회복약 HP바 상승·해독제 아이콘 갱신 |
| 포획 | 투척 `captureFx` → 성공/실패 `captureFx` → 성공: 5.6 포획 종료 / 실패: 다음 행동 | "몬스터볼 투척!" / "포획 실패!" |
| 도망가기 | 성공: "도망 성공!" `fleeFx` → 5.6 도망 종료 / 실패: "도망 실패!" `fleeFx` → 상대 반격(기술→피해) → 다음 행동 | 현행 `fleeCounter` |
| 라운드 종료 처리 | 화상 틱·감전 해제·쿨 감소 메시지는 다음 배너 **앞**에 1초 그룹으로 재생 [권고] | `nextPhase` 메시지 |
- 사망 확인(`checkDeath`)은 규칙상 즉시. 표시: 피해 연출 → KO(흔들림·`ko` 클래스) → 5.6 결과 배너.
- 상대(비행동자)도 같은 연출을 자기 화면에서 재생(현행 `playMsgs`가 양쪽에서 돌아감). 온라인 수신 프레임은 재생 idle 후 적용(3.1).

### 5.5 HP바·방어막 바 [결정]
- HP바(현행 `#hpfill-A/D`) 유지 + 숫자 `hp/maxHp`. 피해·회복 시 너비 전환 애니메이션(약 0.6초, `damageFx` 안에서 완료).
- **방어막 바** 신설: HP바와 같은 폭 기준으로 `shield/maxHp` 비율을 별도 색(`--guard`)으로 HP 위 또는 옆에 겹쳐 표시. 흡수 시 방어막 바가 먼저 줄고 HP는 그 다음. 상태 아이콘 `🛡N` 텍스트는 유지.
- H1 채택 시 "가한 유효 피해 게이지"는 판정 기준과 달라 혼동을 부르므로 **패널에서 제거** [권고]. `recA/recD`는 지표용으로 계속 기록.
- 표시값은 현행 `dispHp` 방식으로 재생과 동기화. 규칙 HP는 즉시.

### 5.6 전투 종료 [결정] — 문구는 뷰어 기준

## 6. 결정론·온라인·AI

### 6.1 lockstep 불변식 [권고 — Saturn 검증 항목]
1. 같은 시드·같은 입력 열에서 `S`·`rand()` 소비 횟수·로그 순서가 변경 전과 동일(회복·함정 공개·판정 변경분 제외).
2. 신규 액션은 `heal` 하나. 폭탄 접촉 발동은 기존 `cell`(이동·텔레포트) 액션의 동기 후속이라 새 프레임이 없다. 자동 턴 종료는 기존 `endTurn` 액션. 하위 메뉴·배너·잠금은 송신 없음.
3. 수신 큐는 잠금 중 보류만 하고 드롭·재정렬 없음. 워치독으로 잠금은 최대 `ms+1000` 안에 풀린다.
4. 오래된 타이머(이전 게임·닫힌 모달·끝난 전투)는 토큰 불일치로 무효. 새 게임 시작 시 `fxReleaseAll`.
5. 비소유자 동기 모달은 현행대로 대기 화면. 배너 중에는 대기 화면 표시도 지연 가능하나 seq는 동기 발급.

### 6.2 입력 잠금 vs 메모 [권고]
- 배너 오버레이가 떠 있는 동안(2초)만 메모 클릭 차단. 표시 유지(hold)·전투 재생 중에는 #94 규칙 그대로(전투 중 메모 불가는 현행 `S.battle` 가드).

### 6.3 AI 지연·속도 [권고]
- AI는 사람과 같은 연출을 기다린다: `aiSchedule/aiScheduleBattle`은 잠금 중이면 idle 콜백에 등록되고, idle 후 `aiDelay`(650ms) 뒤 실행. AI 판단·정책·난수 순서는 불변.
- sim·헤드리스는 연출 0 + `simDelay`로 현행과 동일 속도.
- AI 회복 정책 [권고 — Mars 재량, 공정 관측 준수]: 5급 — 인접 적이 없고 HP < 60%인 공개·미공개 자기 말이 있고 다른 후보 점수가 낮을 때 회복. 5단 — 후보 집합에 `heal(piece)`를 추가하고 기존 평가 함수로 비교. 상대 미공개 말의 회복 플래그는 읽지 않는다.

### 6.4 헤드리스 테스트 호환
- `liveBattleDom()` false → `BAL.fx` 전부 0, 잠금 즉시 해제, 자동 턴 종료는 기존 테스트가 `endTurn`을 직접 호출하므로 **테스트 모드에서는 자동 발화를 끄는 플래그**(`BAL.fx.autoEnd=false` 등) 제공 [권고]. 기존 회귀 1009개 기대값 불변이 목표이며, 판정·함정·회복 관련 단언만 이 계약대로 갱신.

## 7. 수용 기준 (AC) — Mars 구현 · Saturn 독립 검증

보드
1. 사람 턴 시작 시 "나의 턴!" 배너 2초 동안 셀·턴바 클릭이 무시되고, 종료 후 정상 동작. 온라인 비행동자·PVE AI 턴은 "상대 턴!".
1b. 65턴 진입 시 "버닝타임입니다! 2칸씩 이동 가능합니다" 배너가 턴 배너보다 먼저 2초 표시되고 입력이 잠긴다. 경기당 1회(66턴 이후·새 게임 전 재표시 없음), 온라인 두 클라이언트 모두 같은 순서, 송신 프레임 0, 오래된 타이머가 새 게임의 화면을 건드리지 않음. 2칸 이동 규칙·원정 1칸 예외·함정 고정은 변경 전과 동일.
2. 회복 행동: 대상 지정 → `mainUsed`, 즉시 회복 없음. 지정한 플레이어의 턴 종료에 +`round(maxHp×0.05)`, 이어지는 상대 턴 종료에 다시 +5%(한 쌍 10%), 상한 maxHp, 같은 `turn`에 이중 틱 없음. 폭탄·함정·만피 대상 불가. 그 말의 이동·탐색·텔레포트·전투(공격·방어·폭탄·함정·밀어내기)로 즉시 해제되며 같은 턴의 틱보다 먼저 판정. 양 플레이어의 자세 말이 같은 경계에서 함께 틱. 온라인 두 클라이언트 `S` 동일, `rand()` 소비 0.
3. 회복 이펙트·HP 숫자: 소유자 화면 갱신, 상대 화면은 공개 말만. AI는 미공개 말 회복 상태 미참조(코드 검사).
4. 신규 인접 접촉 시 "상대 말 접촉!" 배너 → 상황 문구 → 해결. 복수 대상은 문구 후 클릭 선택, 시간 제한 없음.
5. 폭탄(수동): 폭발 연출 동안 제거된 말이 표시 유지되고 연출 끝에 사라짐. 규칙 결과(생존·제거·지표)는 변경 전과 동일.
5b. 폭탄(직접 접촉): 폭탄이 이동·텔레포트·숲 충돌로 상대와 새로 인접하면 상황 4/5/6 결과가 적용되고 `battlesUsed` +1. 복수 대상은 소유자 선택, 상황 6 이후 재선택 없음. 턴 시작부터 인접했던 상대·능동 클릭으로는 발동하지 않음. 텔레포트 사전 차단 계산에 포함. 상대 폭탄 → 내 말도 대칭.
6. 함정: 걸린 말 `revealed=true`, 함정 `revealed=true`, `immobile=2`. 그 외 말의 `revealed`는 변경 전과 동일(공개 대상 비확대). 로그·거울 문구 갱신. 종료 리빌 정합.
7. 자동 턴 종료: 4.6 조건 충족 시 1초 후 `endTurn`; 강제 대상·forcedQueue·텔레포트 선택·모달 열림·선택 전투 가능 상태에서는 **절대** 자동 종료 없음. 온라인은 행동자만 송신(수신 측 자율 발화 0, 서버 프레임 로그로 검증).
8. 거울 문구표(4.7) 전 항목이 상대 화면에서 맞는 문장으로 표시되고, 비공개 정보(탐색 보상·미공개 정체·미공개 회복)가 새지 않음.
