# README·릴리스 노트 작성 기준

CJ의 #105 승인 방향을 유지한다. 2026-09-16 Notion GDD-19의 중복 문서 정리로 현행 지침을 이관했다.

- README 구성: 게임 소개 / 게임 기능 / 플레이 사진 / 새로운 기능 / 게임 정보 / 플레이 방법 / 저장소 구조 / 라이선스.
- 처음 방문한 플레이어에게 구체적인 게임 경험과 실행 순서를 짧게 설명한다. 내부 QA 수치·조정 이력은 관련 보고서에 둔다.
- 소개 아트·실제 보드·전투·튜토리얼 10장의 갤러리와 원본 링크를 사용한다. 사진의 실제 버전과 캡션을 일치시킨다.
- 최신 정식 패치만 기능 추가·개선·버그 수정·밸런스 항목으로 소개한다. 과거 패치는 GitHub Releases로 연결한다.
- 게임 정보의 버전·날짜·지원 환경·개발자·Star·Fork·출시 정보는 확인된 값을 쓴다. 개발 중 기능은 출시된 기능과 구분한다.
- 시작 방법은 현행 공개 웹 주소와 승인된 실행 경로를 기준으로 갱신한다. 과거 LAN 전용 설명을 현재 외부망 서비스에 적용하지 않는다.
- 과거 Release의 태그·SHA·게시일·자산을 소급 변경하지 않는다. 접속 코드·사용자 정보는 기록하지 않는다.
