# 1. 요약
- **문제:** 현재 전투가 종별 동일 기본 공격 + 전용 스킬 1 + 공용 스킬 1로 구성되어, 실제 플레이에서는 선택 가능한 고유 기술이 1개처럼 느껴지고 최대 6라운드 전투가 반복적입니다.
- **제안:** <span color="blue_bg">추론</span> 각 전투원에게 **기술 4슬롯**을 부여하고, 같은 속성이라도 아키타입과 장착 조합에 따라 전투 리듬이 달라지도록 합니다.
- **권장 슬롯:** <span color="blue_bg">추론</span> 속성 공격기 2 + 보조기 1 + 시그니처 1.
- **목표:** 짧은 전투 안에서 매 차례 “안정 피해 / 상태·조건부 공격 / 생존·준비 / 아키타입 승부수” 중 의미 있는 선택을 만들고, 같은 속성·같은 종의 반복 전투에서도 장착 조합을 읽고 대응하게 합니다.

- **판단:** <span color="blue_bg">추론</span> 첫 검증은 A안이 역할 가독성과 밸런스 통제가 좋아 권장됩니다. B안은 A안의 선택 다양성이 부족할 때 후속 A/B 후보로 유지합니다.

# 4. 종별 기본 장착 4기 배정 원칙
<callout icon="🧩" color="blue_bg">
	아래 배정 원칙과 예시는 모두 추론입니다. “기본 장착”은 커스텀 허용 전에도 각 종의 플레이 감각을 구분하기 위한 시작값이며, 영구 고정을 뜻하지 않습니다.
</callout>
1. **속성 정체성:** 같은 속성 종은 해당 속성 공격기만 2개 장착합니다. 속성 간 기술명·상태는 섞지 않습니다.
2. **아키타입 정체성:** 시그니처는 아키타입별 1개로 고정합니다. 스탯 예산은 GDD-15의 표준형·공격형·방어형·속공형·지속형 기준을 유지합니다.
3. **조합 차별화:** 같은 속성 5종도 공격기 2개 조합, 보조기, 시그니처 중 최소 2개 항목이 다르게 배정되도록 합니다.
4. **안전한 기본값:** 표준형은 안정+효과, 공격형은 안정+고위력, 방어형은 효과+고위력, 속공형은 안정+효과, 지속형은 효과+고위력 조합을 기본으로 하되 보조·시그니처로 전체 구성을 구분합니다.
5. **보조기 분산:** 한 속성 5종 안에서 회복·방어·버프·쿨타임·치료 계열이 고르게 등장하게 하여 같은 속성 편성도 역할 중복을 줄입니다.
6. **중복 구성 방지:** 동일한 4기 조합은 로스터 내 1종만 허용하는 초기 제약을 둡니다.
7. **커스텀 대비:** 커스텀이 허용되면 종별 기본 장착은 추천 프리셋으로 남기고, 자기 속성 공격기 3종 중 2종 + 공용 보조기 1종 + 해당 시그니처 1종의 경계를 유지합니다.

# 5. 기존 규칙과의 정합
## 상태 부여 — D10 유지
- <span color="green_bg">기존 규칙 유지</span> 상태 부여는 D10 확률 판정을 사용합니다.
- <span color="blue_bg">추론</span> 일반 화상·약화70%를 유지하고 v0.4.4 일반 감전은50%로 조정합니다. 확정 시그니처 잔류장은100%를 유지하며 확률 판정은 D10/D17을 따릅니다.
- <span color="blue_bg">추론</span> 동일 상태 연속 발동 불가 규칙을 유지하며, 실패 시 피해만 적용합니다.
- <span color="blue_bg">추론</span> 불의 화상, 물의 공격 약화, 번개의 후공은 상태 판정 대상입니다. 풀의 즉시 흡수·보호막은 상태 부여가 아니므로 D10을 굴리지 않습니다.
## 피해 분산 — ±20% 유지
- <span color="green_bg">기존 규칙 유지</span> 직접 피해가 있는 공격기와 시그니처는 기대값 기준 ±20% 확률 분산을 적용합니다.
- <span color="green_bg">기존 규칙 유지</span> 지속 피해는 고정값을 유지합니다.
- <span color="blue_bg">추론</span> 회복·보호막·버프 수치는 피해 분산 대상에서 제외합니다.
## 6라운드 판정 — 남은 HP 비율(2026-09-08 CJ)
- 각 전투원의 현재 HP ÷ 최대 HP가 높은 쪽 승리, 동률은 기존 방어자 승(PD 채택). 보호막 수치는 HP에 더하지 않지만 보존된 실제 HP는 판정에 반영된다. 대리 하수인의 시작 HP70/100도 별도 보정 없이 적용한다.
- 누적 유효 피해는 지표 전용으로 유지한다.
- <span color="green_bg">기존 규칙 유지</span> 6라운드 종료 시 가한 누적 유효 피해 ÷ 상대 최대 HP를 비교하고 100%를 상한으로 합니다.
- <span color="green_bg">기존 규칙 유지</span> 실제 HP 감소분만 기록하며 초과 피해와 보호막 흡수분은 제외합니다.
- <span color="green_bg">기존 규칙 유지</span> 회복은 이미 기록된 피해를 되돌리지 않고, 지속 피해는 부여자의 피해로 기록하며, 자해는 누적 유효 피해에서 제외합니다.
- <span color="blue_bg">추론</span> 공격형 결정타의 받는 피해 증가와 보조기의 피해 감소는 최종 실제 HP 감소분에만 간접 반영합니다.

## 탐색 기술 교체·속성 판정 (v0.4.4 계약)
- 하수인이 recruit 이벤트를 소비하면 본체와 다른3속성×안정·효과·고위력 중 미장착 후보1종을 받고, 공격 슬롯0/1 중 하나와 교체하거나 유지한다. 거절해도 이벤트 소모, 남은 쿨 승계, 교체 슬롯은 새 사용 전 비공개. 보조·시그니처는 교체하지 않는다. 전투 중 포획 시에는 실제 장착 기술 배열을 복사해 습득 기술도 승계하고 포획 규칙대로 쿨·공개 기록을 초기화한다. 기술 배열이 없는 레거시만 아키타입 템플릿을 사용하며 중립 숲 포획은 표준형 세트를 유지한다.
- 공격기는 기술 속성으로 상성·상태 종류·이펙트·AI 기대 피해를 계산하며 피격 측 방어 속성은 본체를 유지한다. 시그니처·보조·기본 공격은 현행 계약. 후보는 공유 시드, 선택은 기존 온라인 모달 동기화 경로로 전달한다.
- 일반 감전은50%, 화상·약화70%, 확정 잔류장100%. 지속시간은 변경하지 않는다. 4슬롯 감전1R와 레거시 지속형2R 차이는 별도 검토 부채다.
- 수치는 CJ 개선 지시에 따른 Venus 권고의 PD 채택1차값이다. #92 PR#103·#95 PR#99·#96 PR#101은 dev에 통합하고 Saturn 독립 QA를 통과했다(최종 dev ad5f2a8). 불 본체의 번개 효과기가 물에29피해·감전을 주고 피격 방어는 불로 남는 반례, 쿨 승계·포획 실제기술 복사·상대 후보 DOM 비노출을 확인했다. CJ 플레이 QA와 v0.4.4 출시는 남는다. 전투 AI는 기술 속성을 반영하며 보드 단계의 본체속성 근사는 유지한다.
