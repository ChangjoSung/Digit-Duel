# 1. Executive Summary
- **한 문장 피치:** 7×13 대칭 전장에서 정체와 숲 속 위치를 감춘 14개의 말을 운용하고, 탐색과 짧은 속성 배틀을 통해 상대 왕을 제거하는 1대1 턴제 전략 게임
- **장르:** 비공개 정보 기반 PvP 턴제 전술 / 보드게임
- **핵심 경험:** 정체 추론, 블러핑, 숲 매복, 제한 자원 투자, 왕 탐색
- **대상 플레이어:** 짧은 규칙 안에서 추리와 위치 선점, 위험 관리를 즐기는 전략 게임 플레이어
- **현재 단계:** Pre-Production / 저사양 프로토타입
- **프로토타입 목표:** 보드 판단이 탐색 운과 전투 RNG보다 승패에 크게 작용하는지 검증
## 디자인 필러
1. **정보전:** 공개된 행동과 이동 기록으로 상대 말의 역할을 추론한다.
2. **공간전:** 7열 전선과 두 개의 숲을 점유하고 매복·후퇴 경로를 관리한다.
3. **심리전:** 왕을 다른 말처럼 운용하고 폭탄·함정·동료 가능성을 이용해 상대 판단을 흔든다.
4. **짧은 배틀:** 보드 판단의 결과를 최대 6라운드 전투로 빠르게 판정한다.
## 비목표
- MVP에서 강화·초월, 시즌 보상, 대량의 스킬·아이템을 구현하지 않습니다.
- 전투를 별도의 장시간 게임으로 확장하지 않습니다.
- 랭크와 BM보다 코어 보드 플레이를 먼저 검증합니다.

# 3. 경기 준비
1. 각 플레이어는 하수인 6, 폭탄 3, 동료 2, 함정 2, 왕 1을 받습니다.
2. 자신의 3×7 진영에 14개 말을 비공개로 자유 배치합니다.
3. 하수인 6개의 속성과 공용 스킬을 선택합니다.
4. 각 플레이어는 몬스터볼 3개를 받습니다.
5. 양쪽 배치가 완료되면 선공을 결정하고 경기를 시작합니다.
<callout icon="⚠️" color="orange_bg">
	선공 결정 방식과 후공 보정은 첫 테스트에서 선·후공 승률을 기록한 뒤 확정합니다. 무작위 배치는 빠른 대전용 보조 옵션으로 보류합니다.
</callout>
# 4. 턴 구조
1. 턴 시작
2. 이동 1회·탐색 1회·주 행동 생략 중 하나 선택
3. 인접한 적이 있으면 전투 대상 선택
4. 조건을 만족하면 전투 최대 2회
5. 턴 종료
## 주 행동
- 자기 턴에 **이동 1회 또는 탐색 1회**를 선택합니다.
- 턴 시작 시 적과 인접해 있어도 이동·탐색·전투 중 선택할 수 있습니다.
- 후퇴를 선택한 턴에는 탐색할 수 없습니다.
- 이미 인접한 적도 전투 대상으로 선택할 수 있습니다.
- 이동 또는 탐색 후 전투 가능한 적이 있으면 전투를 최대 2회 진행할 수 있습니다.
## 연속 전투
- 첫 전투에서 이동한 말이 승리하고 생존했을 때만 두 번째 전투를 선택할 수 있습니다.
- 두 번째 상대는 최초 이동 종료 시 인접했던 적 중에서 선택합니다.
- 두 번째 전투는 선택 사항입니다.
- 폭탄·함정 발동도 전투 횟수 1회로 계산합니다.
- 첫 전투에서 말이 제거되면 전투하지 않은 상대 말은 기존 정보 상태를 유지합니다.
# 5. 정보와 공개 상태
## 정체 공개
- 모든 상대 말의 정체는 기본적으로 비공개입니다.
- 일반 전투가 시작되면 참여한 상대 말의 정체가 공개됩니다.
- 한 번 공개된 정체는 경기 종료까지 공개 상태를 유지합니다.
- 폭탄·함정만 발동하고 상대 말이 생존한 경우 상대 말의 정체는 UI상 비공개를 유지합니다.
- 행동 결과로 동료·왕 여부가 논리적으로 추론될 수 있으며, 이는 정상적인 정보전으로 인정합니다.
## 위치 공개
- 공터·진영에 있는 말의 위치는 표시됩니다.
- 숲에 진입한 말은 상대 화면에서 위치가 숨겨집니다.
- 상대 말과 인접하면 해당 말들의 위치만 양쪽에 일시 공개됩니다.
- 전투 후에도 정체 공개 상태는 유지하지만, 숲에서 거리가 벌어지면 위치는 다시 숨겨집니다.
- 숲을 벗어나면 위치가 즉시 표시됩니다.
- 첫 테스트에서는 위치 은폐 버전과 위치 공개 버전을 동일한 조건으로 비교합니다.

## 숲 내부 충돌 — 프로토타입 권장 초기값
- 숨겨진 적이 점유한 칸으로 이동을 시도하면 이동 말은 직전 칸에서 정지합니다.
- 충돌한 두 말의 위치를 일시 공개하고 전투 가능 상태로 처리합니다.
- 여러 적과 동시에 인접하면 해당 적들의 위치를 공개하고 최대 2개까지 선택합니다.
- 마지막 목격 칸 표시는 A/B 테스트 항목으로 둡니다.

## 폭탄
- 폭탄은 이동할 수 없습니다.
- 상대가 폭탄을 전투 대상으로 선택했을 때 발동합니다.
- 하수인이 선택하면 하수인과 폭탄이 모두 제거됩니다.
- 동료·왕이 선택하면 폭탄만 제거되고 동료·왕은 생존합니다.
- 생존한 동료·왕은 기존 정체 공개 상태를 유지합니다.
## 함정
- 함정이 발동하면 함정만 제거됩니다.
- 대상 말의 정체는 기존 공개 상태를 유지합니다.
- 대상 말은 해당 말 소유자의 다음 2턴 동안 이동할 수 없습니다.
- 대상은 이동 금지 중에도 상대의 공격을 받아 전투할 수 있습니다.

## 기본 구조
- 일반 배틀은 최대 6라운드입니다.
- 전투를 시작한 플레이어가 1라운드 선공을 잡고, 이후 라운드마다 선공이 교대됩니다.
- 각 말은 자신의 차례에 기본 공격 또는 스킬 공격을 선택합니다.
- 전투 중 HP가 0 이하가 되면 즉시 패배하고 제거됩니다.
- 6라운드 종료 시 누적 유효 피해 비율이 높은 말이 승리합니다.
- 판정패한 말은 남은 HP와 관계없이 제거됩니다.
- 동률이면 프로토타입 초기값으로 방어자가 승리합니다.
## 누적 유효 피해
- 판정 공식: **이번 전투에서 가한 누적 유효 피해 ÷ 상대 최대 HP**
- 누적 유효 피해는 상대 최대 HP의 100%를 초과할 수 없습니다.
- 실제로 HP를 감소시킨 피해만 기록합니다.
- 초과 피해와 보호막으로 흡수된 피해는 기록하지 않습니다.
- 회복하더라도 이미 기록된 피해 점수는 감소하지 않습니다.
- 회복은 HP가 0에 도달하는 것을 막는 용도로만 판정에 기여합니다.
- 화상 등 지속 피해는 효과를 부여한 플레이어의 피해로 기록합니다.
- 자해·포획 실패 피해는 전투 판정 피해에 포함하지 않습니다.
## 전투 상태 유지
- 현재 HP와 스킬 쿨타임은 연속 전투 사이에 유지됩니다.
- 스킬 쿨타임은 0\~2라운드 범위의 초기값으로 설계합니다.
- 상태이상의 전투 종료 후 유지 여부는 전투 수치 명세에서 확정합니다.
## 속성과 상태이상
- 불·물·풀·번개가 순환하는 소프트 카운터 구조를 사용합니다.
- 정확한 상성 방향과 배율은 전투 수치 명세에서 확정합니다.
- **불:** 화상으로 고정 피해
- **물:** 1\~2회 동안 공격력 일부 감소
- **풀:** 피해 일부 흡수 및 회복
- **번개:** 행동 불가 대신 1회 후공 처리
- 회피 효과는 완전 회피가 아니라 피해 일부 감소로 처리합니다.
- 동일 상태이상은 연속 발동하지 않습니다.
## 아이템
- 아이템은 공격 행동을 소모하지 않는 보너스 행동입니다.
- 전투당 최대 2개, 라운드당 최대 1개를 사용할 수 있습니다.
- 동일 아이템은 연속 라운드에 사용할 수 없습니다.
- 일반 아이템은 플레이어 공용 인벤토리 최대 5개를 프로토타입 초기값으로 사용합니다.
- 몬스터볼은 전투 아이템 상한과 일반 인벤토리에서 분리해 최대 3개로 관리합니다.
# 8. 탐색과 숲 이벤트
## 탐색 행동
1. 숲 진입은 이동 행동으로 처리합니다.
2. 진입만으로 이벤트 보상을 획득하지 않습니다.
3. 이벤트 칸에 진입하면 소유자에게만 **탐색 가능한 흔적**을 표시하는 방식을 프로토타입 초기값으로 사용합니다.
4. 다음 자기 턴에 이동 대신 탐색을 선택하면 이벤트가 발생하고 해당 칸은 소모됩니다.
5. 상대에게는 **상대가 숲 이벤트를 발생시켰습니다**라는 중립 문구만 표시합니다.
6. 탐색 후 인접한 적이 있으면 전투를 선택할 수 있습니다.
## 이벤트 배치
- 숲 구역마다 2\~3개의 이벤트 칸을 배치합니다.
- 양쪽 숲의 가까운·중앙·먼 구역별 이벤트 개수를 동일하게 맞춥니다.
- 세부 열 위치는 매 경기 무작위로 정합니다.
- 양쪽 숲의 전체 보상 가치는 동일한 예산으로 구성합니다.
- 이벤트 위치와 내용은 양쪽 플레이어에게 비공개입니다.
## 이벤트 종류
### 아이템
- 동료·왕은 아이템을 획득합니다.
- 하수인은 아이템을 획득하지 못하고 해당 이벤트는 소모됩니다.
- 초기 아이템 후보는 체력 회복, 스킬 쿨타임 감소, 상태이상 치료입니다.
- 무기와 추가 아이템은 MVP 이후로 보류합니다.
### 공용 하수인
- 하수인이 발견하면 해당 공용 하수인의 스킬로 자신의 공용 스킬을 교체할지 선택하고 이벤트를 소모합니다.
- 동료·왕이 발견하면 몬스터볼을 사용해 포획을 시도할 수 있습니다.

# 9. 왕 전투
![](https://prod-files-secure.s3.us-west-2.amazonaws.com/2de2c179-92bd-4b94-92ea-371a4861df09/a6f39484-061f-4eb5-bd69-c7a52cda9d70/digit-dual-king-selection-ui-v1.png)

1. 전투 대상이 선택됩니다.
2. 왕 소유자는 왕 또는 포획 하수인 출전을 비공개로 선택합니다.
3. 양측 선택을 확정합니다.
4. 전투 말과 속성을 공개합니다.
5. 왕이 있는 말이라는 사실을 공개하고 전투를 시작합니다.
- 포획 하수인을 선택해도 해당 전투 패배는 왕의 패배로 처리합니다.
- 왕이 패배하면 즉시 경기가 종료됩니다.
- 폭탄·함정 발동만으로 왕이 생존한 경우 왕의 정체는 기존 공개 상태를 유지합니다.
# 10. 경기 종료
- 상대 왕을 제거하면 즉시 승리합니다.
- 프로토타입은 최대 턴 또는 제한 시간 도달 시 우선 무승부로 처리합니다.
- 시간 초과 점수 판정은 전투 회피 데이터를 확보하기 전까지 사용하지 않습니다.
- 경기 중 획득한 아이템과 포획 하수인은 경기 종료 시 삭제됩니다.
- 무승부가 과도하면 숲 위치 은폐 해제와 왕 구역 공개를 사용하는 연장전을 별도로 실험합니다.

## Acceptance Criteria
- [ ] 배치부터 왕 제거 또는 제한 종료까지 중단 없이 진행할 수 있다.
- [ ] 모든 말 접촉 조합에 판정 결과가 존재한다.
- [ ] 탐색과 이동·전투 사이에 명확한 비용 차이가 있다.
- [ ] 위치 은폐·정체 공개 상태를 플레이어가 혼동하지 않는다.
- [ ] 합리적 추론 없이 왕을 무작위로 맞히는 전략이 지배적이지 않다.
- [ ] 전투 가능한데 회피한 횟수와 무승부율을 기록한다.
- [ ] 공격자·방어자 및 선공·후공 승률을 분리 기록한다.
- [ ] 숲 은폐 A/B 버전의 경기 시간과 만족도를 비교한다.
# 12. 랭크와 BM 원칙
- 랭크전은 능력치를 정규화하고 모든 전투 옵션을 동등하게 제공합니다.
- 수집형 하수인과 공용 스킬은 성능 우위가 아닌 횡적 선택지로 설계합니다.
- 강화·초월은 랭크전에 적용하지 않습니다.
- BM은 말 외형, 배틀 연출, 이펙트, 말판·숲·왕국 스킨을 우선합니다.
- 급·단·시즌 보상은 코어 전투 검증 이후 별도 문서에서 설계합니다.
