# 필수 QA 운영 원칙 — 2026-09-16 CJ 지시

Saturn은 변경 범위의 필수 검증만 수행한다. v0.4.10 때처럼 네트워크 동기화를 브라우저에서 반복 조작하며 과도한 시간·토큰을 쓰지 않는다.

- 먼저 Issue 완료 조건과 변경 위험에 맞는 최소 검증 목록을 정한다.
- 기존 자동 테스트·헤드리스 회귀와 코드 대조를 우선한다. 같은 시나리오를 여러 도구로 중복 확인하지 않는다.
- Computer Use로 직접 클릭하는 브라우저 검증은 자동 검사로 확인할 수 없는 시각·입력 문제에만 제한한다. 필요한 대표 흐름만 한 번 확인한다.
- 네트워크 코드·동기화 계약 변경 또는 구체적 회귀 근거가 없으면 네트워크 수동 매트릭스를 반복하지 않는다. 필요한 경우에도 자동 프로토콜 검증과 대표 경계 사례를 우선한다.
- 통과한 검사는 관련 수정·실패·새 위험이 생겼을 때만 다시 실행한다. 이유 없는 전체 재실행·장시간 AI 시뮬레이션·기존 릴리스 전수 재검증은 하지 않는다.
- 필수 CI와 변경에 직접 필요한 회귀는 생략하지 않는다. 검사 수를 줄이려고 기대값을 구현에 맞춰 낮추지 않는다.
- Saturn은 읽기 전용이며 제품·테스트·보고서 파일을 수정하지 않는다. 판정과 근거는 메시지로 PD에게 전달하고 PD가 기록한다.
- 보고에는 실행한 검사·결과·미검증 한계를 간결히 적는다. 미검증 범위를 PASS로 주장하지 않는다.

#233 적용: 전투 계산·순서·상태·방어막·초기화의 결정론적 경계 검사와 영향받은 기존 헤드리스 회귀, Saturn의 독립 코드/AC 대조, PR 필수 CI. 수동 네트워크 플레이·전체 밸런스 시뮬레이션은 기본 검증 대상이 아니다.
