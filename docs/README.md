# Digit-Duel 문서 진입점

현재 상태·업무·승인·팀·QA·인수인계는 **[CHANGJO GAMES Org Chart and R&R](creat2ve/CHANGJO_GAMES_ORG_RNR.html)** 한 곳에서 관리합니다.

- [게임 소개](../README.md)와 [Git/CI 기여 안내](../CONTRIBUTING.md)는 기존 진입점입니다.
- [실행 모델 설정](creat2ve/worker-models.json)은 기계 설정 원본입니다.
- [마일스톤 기록](milestone/README.md)·[릴리스 기록](releases/README.md)·[Notion 보관본](creat2ve/notion-archive/2026-09-16/README.md)은 작성 당시의 증거입니다. 현재 지시로 재활성화하지 않습니다.

업무 현황을 이 파일에 중복 기록하지 않습니다. 과거 문서의 삭제·최신화 판정과 증거는 운영 원장의 `doc-policy` 절을 따릅니다.
