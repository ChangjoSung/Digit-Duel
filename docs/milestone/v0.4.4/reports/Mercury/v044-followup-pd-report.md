## 동기화 — 확정된 결함과 추가 감사 구분

확정된 #104 결함은 온라인 수신 재생 중 상대 말의 가시성을 로컬 뷰어로 판단한 것이다. 행동자는 자기 숲의 숨은 상대 말로 2칸 이동해 충돌 처리하지만, 상대 클라이언트는 그 말의 소유자이므로 보이는 말로 판단해 메모 분기로 빠졌다. 양측 상태가 갈라졌다. `visibleTo(S.current,p)`로 행동자 시야를 사용하도록 바꿨다.

이 수정은 행 반사 기능 도입 전 코드에도 존재했던 결함에 대한 것이다. Saturn은 신규23·기존852·실제 Chrome22 검사를 통과했고, 이전 조건을 메모리에서 복원하면 결정적 충돌 사례가 실패함을 확인했다. 근거: [Mars 보고](../../issues/104/Mars/issue104-mars.md), [Saturn 보고](../../issues/104/Saturn/issue104-saturn.md), [PR107](https://github.com/ChangjoSung/Digit-Duel/pull/107).

CJ는 같은 서버·같은 버전 사용을 확인했으며, 65턴 이전 직접 관찰 여부와 별개로 2P 시점 전환·중앙선 통과 전 경로를 점검하도록 추가 지시했다. 현재 계약은 2P의 화면 행만 `14-r`로 바꾸고 열은 유지한다. 따라서 P1 좌상단은 P2 좌하단에 대응한다. CJ의 좌상단→우하단 언급은 원인 가설로 다루며 새로운 회전 방식 도입 요청으로 해석하지 않는다.

Mars_3의 1차 감사에는 65턴 이전 전체 횡단이 빠져 PD가 보완을 요청했다. 보완본에 대한 Saturn 검사에서는 소유자 표시 오류 28건을 기록하고도 성공으로 종료하는 감사 도구 결함이 드러났다. Mars_3는 실패 집계, 구간별 실제 검사 횟수, 전투 완료 확인을 수정했다. 이 이력은 [첫 Saturn 판정](../../issues/104/Saturn/issue104-orientation-saturn-first.md)에 보존한다.

rev3의 [최종 Saturn 재검수](../../issues/104/Saturn/issue104-orientation-saturn-final.md)는 PASS다. 14경기(7열×65턴 전후)의 양측 전체 횡단을 포함한 헤드리스8,916/0, 실제 Chrome20/0, 칸 클릭80회 전송 좌표 불일치0, 전체 보드 픽셀·hit-test118회, 공개 하수인 이미지12/12씩을 확인했다. 독자적인 소유자 오류 변이28건은 모두 실패로 집계되고 종료 코드1을 반환했다. 실제 브라우저의 65턴 이전 경로는 양측2/12행까지, 이후 경로는 반대편 숲5/9행까지이며 이후2/12행까지는 헤드리스가 담당한다. 비교 대상은 명시된 공통 상태 필드이며 모든 UI 표식 위치를 검사한 것은 아니다. 이 검사에서 추가 결함을 찾지 못한 것과 CJ의 원래 경기 전체를 재현한 것은 구분한다.

## #106 승인 계약과 검수 범위

- 회복 지정은 주 행동을 소모한다. 지정한 턴 종료부터 나·상대 각각의 턴마다 최대 HP 5%를 회복하며 여러 말에 지속할 수 있다. 만피에서도 자세를 유지하고, 해당 말의 행동·전투로 해제된다. 미공개 상대 말의 회복 상태는 노출하지 않는다.
- 함정과 걸린 말 모두 공개한다. 폭탄은 직접 새로 접촉해도 발동하며 대상별 기존 생존 규칙을 적용한다.
- 65턴 진입 시 정확한 버닝타임 문구를 2초간 먼저 표시하고 일반 턴 배너를 잇는다. 전투4메뉴, HP/보호막 바, 행동·피해·결과 연출을 적용한다.
- 6라운드 판정은 남은 HP 비율을 비교하고 동률은 방어자가 이긴다. 보호막은 HP 비율에 더하지 않는다.
- 할 수 있는 행동이 없을 때만 자동으로 턴을 종료한다. 선택 전투·강제 대상·텔레포트·모달·연출이 남으면 종료하지 않으며 온라인 행동자만 전송한다.

검수는 실제 기본 연출 시간을 사용하는 브라우저와 연출 시간0인 헤드리스를 구분한다. 양측 상태·난수·프레임 순서, 연출 중 입력, 오래된 콜백, 회복 중복 틱, AI 공정 관측, 기존 규칙 회귀를 포함한다.

첫 후보a20be021는 기존 자동 검사 통과 후에도 Saturn이 세 결함을 재현해 REVISE했다: 옛 게임 메시지 콜백이 새 큐를 지움, 보호막보다 HP가 먼저 갱신됨, 도망 성공 뒤 추가 접촉 배너가 즉시 사라짐. 새 게임·같은 게임 재진입을 보완했고, 보호막/HP는 동기 setter 순서만 바꾸는 것으로 끝내지 않고 기존 피해2초 안에서 실제 표시 단계를 분리했다. 최종 후보a4932cb8…의 [표시 수정 보고](../../issues/106/Mars/issue106-shield-mars.md)와 [첫 Saturn 판정](../../issues/106/Saturn/issue106-saturn-first.md)을 함께 보존한다. 작성자 규칙198·타이머36 통과는 독립 판정과 구분한다.

최종 제품 SHA256은 `a4932cb80a1407fc728ace6ee918315880840c76010de7b21361a7f618e97280`다. 이 파일에 대해 Saturn은 규칙198/0·실시간 타이머36/0·기술교체116/0·cycle5 69/0·승인 아트199/0·현재 제품 시점 감사8,910/0을 확인했다. 공정 관측은 숨은 상태450+450개 대체에서 차이0이었다. 표시 지연을 제거한 독립 변이는6개 검사가 실패했고, 최신 표시 갱신 가드를 제거하면 K4b가 실패했다. 실제 Chrome 주 검수도50/0이며, 버닝타임 구간만 빠른600ms로 검증했다.

기본시간 보완 도구 `756a2236…`의 독립 재실행은 **65/0**, 작성자 실행은 **64/0**이다. Saturn 실행은 PVE AI 선공에 대한 추가 검사P1b를 지나 1건 많으며, 같은 검사를 반복 합산한 수치가 아니다. 두 실행 모두 기존390px 전체 페이지 넘침2건을 범위 밖 WARN으로 분리했다. Saturn 실측에서 보호막 감소 시작 때 HP 너비는 옛 값90px를 유지했고,615ms 뒤 HP가 감소해 두 바 모두 피해2초 안에서 변화했다. 양측 버닝타임 배너는2012/2013ms 뒤 일반 턴 배너2015ms로 이어졌다. 실제12행동 후100% 동률 판정은 방어자 승리였으며, 가방 사용 뒤 행동자·라운드·phase가 유지됐다. [보완 작성자 보고](../../issues/106/Mars/issue106-browser-mars.md)와 [최종 Saturn 보고](../../issues/106/Saturn/issue106-saturn-final.md)를 참조한다.

보완 검수는 자연 로스터·수동 배치·실제 릴레이 연결 후 재현 조건을 맞추는 명시적 픽스처를 사용했다. F-pve·F-B1·F-B2·F-tie와 추가F-bt65, 총5개 명칭을 구분한다(작성자 요약의4건은 추가 BT 조건을 제외한 수). 모든 조건이 자연 경기만으로 형성됐다고 주장하지 않는다. 최종 후보 캡처18장은 누락0이며, 이전 진단 실행의 스크린샷 응답 정지는 도구의 요청 제한과 대상 탭 전면화로 보완했다.

작성자 초기 보고의 기존 회귀 합계1,199는 계산 오류다. 나열된11개 스위트 합계는 **1,032**(676+199+157)이며 최종 보고는 이 수치를 따른다. 기존 보고의171은 첫 후보,182는 중간 수정본,198은 최종 표시 수정본 수치다. 위 최종 후보 재검사와 겹치는 검사를 합산해 부풀리지 않는다.

## 객관적 한계와 후속

- HP70/100으로 시작하는 전투 포획 예비 하수인은 HP 비율 판정에서 불리하다. 이번에 임의 보정하지 않은 알려진 트레이드오프다.
- 고정 연출 때문에 전투의 대기 시간이 늘어난다. 타이머가 브라우저 정지·백그라운드 제한을 넘어 실제 벽시계 시한을 보장한다고 주장하지 않는다.
- 실제 서로 다른 LAN 기기·모바일 브라우저·Chrome 외 브라우저와 사람 플레이 통계는 별도 검수 범위다. README 좁은 화면 검수를 게임 모바일 검수로 간주하지 않는다.
- 게임의390~400px 전투 메뉴와 페이지 전체 반응형 처리는 다르다. 기존 고정 보드와 우측 패널 때문에 페이지 전체 가로 넘침은 남아 있다.
- Worker가4개 기존 테스트를 Git으로 복원하고 프로필 접두사로 Chrome을 종료한 절차 위반은 [사건 기록](../../issues/106/Mercury/issue106-pd-incident.md)에 남겼다. Saturn 실행에 대한 영향은 관찰되지 않았지만 전체 종료 대상의 소유권은 입증되지 않았다. 불확실한 임시 프로필은 삭제하지 않았다.
- 전체 기술·상성·감전·공용 하수인 및 추가 아트 검토는 v0.4.5 계획이다. #95가 모든 대진을 개선한다는 결론은 내리지 않는다.
- 2026-09-08 CJ의 최종 QA PASS 및 Release 지시를 수락했다. [v0.4.4 Release](https://github.com/ChangjoSung/Digit-Duel/releases/tag/v0.4.4)에 출시 기록을 남기고, #93·#104·#105·#106 및 Milestone10을 완료 처리한다. v0.4.5는 별도 계획이다.
