## 표시 계층

- **(3) 출전 준비 탭** — 원인은 `uiPrep()` 이 `uiApply()` 만 부르고 `renderSetup()` 을 다시 그리지 않아 `aria-pressed` 가 01 에 고정된 것이었다.
  `data-prep` 은 실제로 바뀌어 **내용은 전환되고 있었다** — CJ 의 "시스템은 정상, UI 전환만 안 됨" 관측과 정확히 일치한다.
  `uiApply()` 가 `UI.prep` 을 보고 두 탭의 `aria-pressed` 를 다시 맞추도록 고쳤다. 스크롤은 건드리지 않았다 — 배치 단계에서는 말판이 위에 그대로 보여야 배치할 수 있다.
- **(4) 전투 하위 메뉴 '← 뒤로'** — 직전 REVISE 에서 제목 왼쪽(좌상단)에 올렸던 버튼을 **네 하위 패널 다음·전투 이력 앞**의 전체 폭 버튼으로 내렸다.
  핸들러는 종전 그대로 `window.__menu(null)` 시맨틱 호출이고, 전투에서 강제로 빠져나가는 버튼은 만들지 않았다. 화면 좌상단의 전역 뒤로가기(`#btnBack`)와는 별개다.
