## 14. 이 문서가 확정하지 않는 것

- **아키텍처를 Venus가 확정하지 않았다.** GDD-22 본문은 Jupiter의 `../Jupiter/analysis.md`를 읽어 **인용·번역**한
  것이며, Venus가 새 기술 결정을 추가하거나 Jupiter/Saturn의 진행 중 판정을 확정으로 승격한 곳은 없다.
- **Saturn 최종 PASS를 주장하지 않는다.** Mercury 기록상 Saturn은 여섯 지적의 해소를 확인하고 마지막 1건
  (`FINISHED` 허용 명령표의 `leave` 누락)을 REVISE로 남겼으며 Jupiter가 이를 반영했다. **그 이후의 최종 PASS
  판정은 기록되지 않았으므로** GDD-22 §6과 `Version` 속성 모두 "지적 반영 / 최종 PASS 미기록"으로 적었다.
- **CJ 승인을 주장하지 않는다.** §5의 5개 항목은 전부 `기획 필요`다.
- **코드·Git·GitHub는 건드리지 않았다.** 이번 세션의 파일 변경은 `notion-sync.md`와 이 파일 두 개뿐이다.
