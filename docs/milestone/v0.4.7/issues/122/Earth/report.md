타이틀·로비·전투 전체화면·로비 복귀/재대전은 미구현 구조 제안이다. 핫시트 기기 넘기기, 온라인 대기/취소, 공개 로그 접근, 비공개 출전 선택은 보존 전제로 세부 화면을 생략했다.
