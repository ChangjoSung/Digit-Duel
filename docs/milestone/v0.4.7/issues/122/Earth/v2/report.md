# [피드백] #122 — 현재 HTML 기준 v2

Earth · 2026-09-10 · **제안 아트, CJ 최종 승인 아님.** v1 파일은 역사 자료로 보존한다. 이번 작업의 범위는 최신 dispatch의 CJ 지시이며 과거 스냅샷의 rough-only 범위를 현재 지시로 확대 해석하지 않는다.

보드의 일반 칸은 단색 네이비/진영색이고 숲 칸 내부 아래에만 각진 잎 군집을 둔다. 선택·이동·공격 테두리는 잎 위에서 식별되며 말 얼굴과 HP를 가리지 않아야 한다. 예시 배치는 미공개 상대 `?`와 공개 상대를 함께 보여주기 위한 부분 배치로, 실제 저장 경기나 전체 말 수의 증거가 아니다. 실제 공개 규칙·좌표 변환은 현행 구현을 따른다.

기존 말의 파랑/빨강 프레임·공개 정보 행을 유지한다. 왕/동료는 #124의 새로운 얼굴만 연결하고 팀별 전신 이미지를 중복 제작하지 않는다. 미공개 말은 정체를 드러내는 새 얼굴·HP를 표시하지 않는다. 현재 색·숲·레이아웃 함수는 `demo/index.html`에서 확인했고 기존 승인 `fire_std`/`water_std`의 icon/battle PNG를 읽기 참조했다.

전투는 제공된 휴대용 몬스터 전투 참조의 **배치만** 따른다. 게임명·메뉴·HP/보호막·기술 체계는 Digit Duel을 유지한다. 기존 전면 아트를 그대로 배치했으며 뒤집기나 실제 후면 아트로 주장하지 않는다. 싸우기 하위는 현행 4슬롯, 전부 불가 시 현행 수동 턴 종료이며 왕·동료 본체의 기본 공격은 유지한다. 가방의 패키지, 비공개 출전/재고/기술, 관전자·온라인 대기/핫시트 차례 정책은 생략한 화면에서도 보존 대상이다.

원고는 스크립트·HTML·외부 네트워크 참조 없는 SVG이며 승인 PNG를 상대 로컬 경로로 참조한다. 원고만 다른 위치로 옮기면 이미지 경로가 깨질 수 있으므로 저장소 위치를 보존한다. 기존 Chrome CLI로 [board-v2.png](board-v2.png)와 [battle-v2.png](battle-v2.png)를 각각420×910/420×780의1:1 크기로 렌더하고 직접 시각 확인했다. 보드는 잎 군집을 수정한 최종본을 다시 확인했으며 말·HP/속성·비공개`?`가 식별된다. 전투128px 아트·HP판·하단 명령은 겹치지 않는다. 반응형·제품 기능·경기 결과 QA를 이 정적 그림으로 주장하지 않는다. 자원 정리의 정책 차단은 [통합 아트 보고](../../../124/Earth/art-report.md)에 기록한다.
