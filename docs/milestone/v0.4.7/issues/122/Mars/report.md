## 3. 수풀 표시 (CJ 2026-09-10 추가 피드백 · 확정)

- **은폐 규칙은 하나도 바뀌지 않았다.** `visibleTo`·`known`·인접·`tempReveal`·메모 판정과 좌표 변환이 종전 그대로다. 비인접 수풀의 상대 말은 칸에 chip·img·`?`·메모 DOM 이 **아예 만들어지지 않는다** (실측: 해당 칸 `children.length===0`, `innerHTML===""`).
- 위치가 드러난(인접·일시 공개) 상대 수풀 말은 **종전대로 미공개 `?`** 다. 새 표시 규칙을 만들지 않았다.
- 보이는 수풀 말은 **양측 모두** 카드 바탕 `0.5` · 본체 `0.7`, 정보행·`?` 는 `1` (실측값 그대로). 일반 칸의 말은 `1`.
- 클래스는 **칸이 실제 숲인가**로만 붙는다(`inForest({r})`) — 가시성 판정과 분리돼 있어 규칙 경로에 끼어들지 않는다.

## 4. 보존 (확정 — 코드·테스트로 고정)

- 보드 종료와 전투 행동 종료는 계속 다른 계층이다 (보드 상시 종료 버튼 없음 + 조건부 `싸우지 않고 종료` / 전투는 4슬롯 전부 불가 + 소유자 화면일 때만 수동 `턴 종료`).
- **전투는 인덱스 모달이 아니라 시맨틱 액션**이다. `battleModal` 의 `buttons` 는 계속 빈 배열이고 `__act`/`__pass`/`__flee`/`__throwBall`/`__openPkg` 단일 경로다 (Venus I-4). 새 서랍·탭·타이틀은 모달이 아니라 DOM 표시 전환이라 `NET.modalSeq` 를 건드리지 않는다 (I-2 해당 없음).
- 비공개 계약: 핫시트 교대 차단 모달 · 비공개 출전 선택 · 온라인 매칭 대기/취소 · 상대 아이템/패키지/로스터 마스킹 · 숲 은닉과 인접 관측 · 추측 메모 뷰어 격리.
- 규칙·수치·난수 흐름·온라인 프로토콜·서버·계정·매칭을 바꾸지 않았다. 새로 `rand()` 를 부르는 곳이 없다.
- 튜토리얼 모달은 **종전 어두운 팔레트 그대로**다 (`#tutOverlay` 안에서 색 토큰 값을 되돌린다). 승인된 10단계 화면·기존 촬영 증빙이 이번 리스킨으로 바뀌지 않는다.

## 5. #128 경계 (확정)

`location.reload()` 출구를 없애고 같은 문서 안의 `[로비로 돌아가기]`·`[다시 대전]`으로 바꿨다. 새 저장 키·새 게이트가 없고 `TUT.seenThisLoad` 를 건드리지 않으므로 — 새 문서 로드는 1단계부터 자동 표시, 같은 문서의 로비 복귀·재대전·모드 변경은 추가 표시 없음. 실제 Chrome 3폭과 헤드리스 양쪽에서 확인했다.
로비 복귀는 온라인 상태를 완전히 해제한다(`netLeave`) — 이 정리 없이 돌아가면 다음 오프라인 경기가 온라인 게이팅·보드 반전·인덱스 중계를 물고 간다 (Venus F8). 접속 코드는 탭 메모리에서 버려 재입력을 요구한다.
