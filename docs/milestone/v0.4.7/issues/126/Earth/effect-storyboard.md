# [피드백] #126 — 승패 효과 스토리보드 v1

Earth · 2026-09-10 · **시각 제안 / CJ 최종 아트 승인 아님.** 구현은 Mars CSS/DOM 소관이며 게임 상태·결과·대기 시간 계약을 바꾸지 않는다.

전투 결과 배너의 기존 **2500ms**는 보존하고, 그 안의 강한 효과 동작 구간만 약 **1.1–1.2초**로 배분한다. 크기·움직임·명암의 한 번의 정점으로 힘을 주며 1200ms 이후에는 결과 글자를 유지하고 기존 2500ms가 끝나면 복귀한다. 반복 점멸이나 추가 대기는 없다. 아래 수치는 내부 효과 배분 제안이며, 기존 배너가 1200ms라는 뜻이 아니다.

| 시간 | 전투 승리 | 전투 패배 |
|---|---|---|
| 0–120ms | 승자 발밑으로 빛을 응축, 외곽을 잠깐 어둡게 | 패자 중심으로 암부 응축, 얇은 균열 예고 |
| 120–300ms | 금빛/아이보리 빛기둥 + 1회 충격파가 무대 폭으로 확산; 큰 `전투 승리` | 비대칭 검붉은 충격 쐐기 + 어두운 방사 균열; 큰 `전투 패배`, 패자만 뒤로 10–16px 밀림 |
| 300–750ms | 10–16개 각진 빛 입자가 바깥·위로, 링은 투명해짐; HP판과 승자는 읽힘 | 6–10개 어두운 파편이 아래로; 짧은 충격 흔들림 1회 후 정지, 패자 소멸은 현행 결과와 동기화 |
| 750–1200ms | 입자·빛 잔상 정리, 결과 문구 유지 | 균열·암부 정리, 패배 문구 유지 |
| 1200–2500ms | 기존 결과 문구 홀드 후 기존 보드 복귀 | 기존 결과 문구 홀드 후 기존 보드 복귀 |

색 제안: 승리 `#ffd84d / #fff2c4`, 패배 `#ff5b6e / #421d35 / #12151c`. 화면 전체를 순백색으로 덮기보다 무대 안 중앙광과 어두운 외곽의 대비로 강도를 준다. 문구와 실제 승패가 색보다 우선하며, 이미 공개된 전투원만 효과 대상으로 쓴다. 관전자·핫시트는 특정 시청자 승리로 오인하지 않도록 실제 승자 이름과 결과를 함께 표시한다.

| 결과 | 시각 어휘 / 결과 문구 | 구분 |
|---|---|---|
| 도망 성공 | 청회색 가로 바람 1회, `도망 성공 — 전투 종료` | 금빛 축포·승리 왕관 없음. 도망 실패는 실패 안내 후 현행 행동 진행 |
| 포획 성공 | 작은 중립색 수렴 링, 대상이 포획 지점으로 모임; `포획 성공 — 전투 종료` | 경기 승리처럼 화면 전체를 축하하지 않음. 실패는 현행 실패 피드백 |
| 전투 판정 동률 | 실제 방어자 승리 결과의 승/패 연출 | **전투 무승부 화면은 만들지 않음**: PD 확인에 따라 동률은 방어자 승 |
| 경기 무승부 | 균형 잡힌 청회색 두 선이 중앙에서 정지; `경기 무승부` | 패배 균열·승리 폭발 없음, 중립 결과판 |
| 경기 승리/패배 | 기존 경기 결과판에 큰 `경기 승리` / `경기 패배`와 실제 사유·승자 | 전투 종료와 다른 최상위 화면. 1.2초 효과가 끝나도 결과판은 기존 동작을 따름; 보드 복귀로 오인 금지 |

도망·포획은 별도의 기존 1200ms 상수와 결과 경로를 그대로 따르며 2500ms로 연장하지 않는다. 저동작 환경에서는 충격파 확대·밀림·흔들림·입자 이동을 생략하고 대비 프레임과 결과 문구로 같은 결과를 전달하는 방향을 제안한다. 효과 수명·입력 잠금·재시작 정리는 Mars가 기존 결과 흐름에 맞춰 구현·검증한다. 이 문서는 애니메이션 구현이나 플레이 QA 증거가 아니다.
