## 2-1. 사용자 안내에 남긴 것과 여기로 옮긴 것

CJ 지시(2026-09-10)에 따라 사용자 안내(README · 릴리스 노트)는 **플레이어가 바로 겪는 세 가지**만 짧게 남겼다.

1. 새로 접속하거나 새로고침할 때마다 튜토리얼이 1단계부터 열린다.
2. 같은 게임 화면 안에서는 자동으로 다시 열리지 않는다.
3. [건너뛰기] · <kbd>Esc</kbd>로 즉시 닫고, `?` 버튼으로 언제든 다시 볼 수 있다.

아래 엔지니어링·이력 세부는 사용자 안내에서 빼고 이 보고와 검증 기록에 둔다.

- **저장 방식** — 자동 표시 생략은 브라우저별 `localStorage` 저장에 근거한 기존 정책이었다. 같은 브라우저 · 같은 주소 재방문에서 생략되는 동작은 그 정책대로였다.
- **재표시하지 않는 내부 사건** — 새 게임 · 재대전 · 모드 변경 외에 **WS(온라인) 연결 복구 · 탭 복귀 · BFCache 복원**도 자동 재표시 대상이 아니다. 즉 판정 기준은 "새 문서 로드인가"다.
- **과거 미재현 경위** — 앞선 확인에서 실제 Chrome의 독립 프로필 두 개 · 같은 HTTP origin으로 봤을 때 한쪽의 완료가 다른 쪽에 넘어가지 않았고, `localhost`와 `127.0.0.1`도 분리됐다. 즉 **처음 신고된 '다른 PC 사이의 공유' 증상은 미재현**이다. 이후 CJ가 준 상세 증상이 위 기존 정책으로 설명돼, 원인 추적 대신 **표시 정책 변경**이 승인됐다. 이번 변경을 그 신고의 재현·해결로 소급하지 않는다.
- **범위 밖** — 계정 도입, 서버 재시작 시 저장값 전체 삭제. 튜토리얼 외 저장값은 건드리지 않는다.
- **캡처** — #128은 튜토리얼이 **언제 열리는지**만 바꾸고 10단계 그림·내용은 바꾸지 않으므로 재촬영이 필요 없다. 기존 10장의 출처(#146 검수 커밋 `aa6998ae8d2ca8b5fc8136c5fa19bc6aca5c12ea`와 그 manifest)는 그대로 두고 **#128의 제품 촬영으로 옮겨 적지 않았다.**
