# #295 턴 상점 — 구현 전 최종 보고

[피드백 · 구현 전 보고] 2026-10-02 Mercury 취합. **분석 완료 / CJ 구현 승인 대기**입니다. 아래 화면 배치와 실행 계획은 권고안이며 제품 구현·렌더 검증·QA 판정이 아닙니다.

## 결론

#293 시작 상점의 최종 화면 틀과 공용 부품을 턴 상점에 적용합니다. #294에서 CJ QA PASS를 받은 TopBar, 실제 8스탯·잠긴 미래 스킬을 포함한 하수인 상세, 가방 상세도 그대로 재사용합니다.

현재 두 상점은 이미 `shopHtml`과 `window.__shop`으로 카드·거래를 공유합니다. 차이는 머리줄, 시너지 위치, 왕·동료 구역, 화면을 담는 컨테이너입니다. 따라서 기존 UI 함수와 CSS를 재배치하는 작업으로 한정하는 것이 타당합니다. 새 의존성·새 아트 자산·Core 경제·서버 전송 필드는 현재 분석에서 필요하지 않습니다.

| 양측 완료·만료 후 | 설명·확인 창을 정리하고 진행 중인 말판으로 복귀 |

컨테이너는 **기존 모달의 상태·시계·종료 경로를 유지하고, 보이는 폭과 높이를 시작 상점의 세로 프레임에 맞춘 넓은 시트**로 만듭니다. 별도 화면 경로나 새 단계 상태는 만들지 않습니다. 좁은 종전 팝업을 그대로 두면 오른쪽 열과 50/50 TopBar를 넣은 뒤 본문 폭이 부족해집니다. 모바일에서는 viewport 폭을 쓰고 PC에서는 기존 중앙 432px 세로 프레임을 유지합니다. 실제 320/390px 배치는 구현 후 확인합니다. GDD의 “모달”은 기존 상태·입력 차단 의미로 유지하며 시각 규격은 승인 뒤 Venus가 명시합니다. Venus의 넓은 시트 권고와 Mars·Earth의 모달 수명 보존 권고를 이 방식으로 조정했습니다.

왕·동료는 시작 상점과 같은 **3줄의 말 그림 + 속성 아이콘 5개**를 권고합니다. 턴 상점에서는 `🎟 ×N`을 표시하고, 생존한 대상의 다른 속성을 누르면 기존 티켓 사용 확인 1회와 기존 `shopTicket` 처리로 연결합니다. 티켓 없음·사망·현재 속성은 비활성 사유를 제공합니다. 무료 변경 규칙은 가져오지 않습니다. 이 배치 변경은 CJ 승인 대상이며 현재 제품에는 적용하지 않았습니다.

턴 상점에는 배치 단계가 없으므로 01→02→03과 상대의 준비 단계 표식을 넣지 않습니다. 상대 상점 완료 여부를 새로 공개하지 않습니다. ⚙의 온라인 기권은 기존 확인·단절 잠금 규칙을 따르고, 오프라인의 종료 기능은 현행대로 유지합니다.

## 정적 분석으로 발견한 위험과 처리 기준

1. **준비 화면 함수를 통째로 복사하면 시계·단계가 틀립니다.** `flowHeadHtml`은 준비 전용 `prepClock`·좌석 단계·나가기 로직을 포함합니다. `topBarHtml`, 카드, 시너지 열, 기존 기권 메뉴만 재사용합니다.
2. **컨테이너 CSS와 이모티콘 층이 겹칠 수 있습니다.** 준비 프레임 스타일은 `#app[data-flow]` 아래에 있고 모달은 밖에 있습니다. 시너지 열의 기준 상자·스크롤·높이와 TopBar 50/50를 시트 내부에 맞추고 선택자를 해당 상점 범위로 제한합니다.
3. **확인 취소 후 온라인 기권 진입점이 사라질 가능성이 있습니다.** Mars가 `back → shopShow(false)`와 네트워크의 기권 버튼 추가 경로 차이를 찾았습니다. 아직 실행 재현은 하지 않았습니다. 공용 상점 머리줄에 메뉴를 두고 해당 경계 흐름에서 확인합니다.
4. **완료 연타와 닫힘 후 잔존 창을 확인해야 합니다.** 기존 요청 가드와 공용 정리 함수를 사용하고, 완료·시간 만료·단절·기권·새 경기에서 설명/확인 창과 시계가 남지 않는지 검증합니다.
5. **시너지 계산을 UI에서 다시 만들면 안 됩니다.** `ecoSynView`는 정기 상점에서 현행 `synView`에 사망 동료 정보를 더합니다(`core.js:2307`). 이 기존 산식과 추가 칩을 사용하고 거래·티켓 확정 뒤 실제 값을 비교합니다.
6. **모바일 폭은 아직 실측하지 않았습니다.** 긴 닉네임은 기존 말줄임, 대표 얼굴·테두리·VS는 유지합니다. 시간 정지 표시·큰 코인 수·승급 표시·상품 구매·설명 창이 320/390px에서 잘리거나 겹치지 않는지 확인합니다.
