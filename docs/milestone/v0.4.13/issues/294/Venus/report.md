## 확정 해석 (Venus — CJ 원문 문장은 아님)

- 대표가 없을 때 그림 = 종전 일반 프로필 아이콘. 화면의 작은 `나`/`상대` 글자는 접근성 이름으로(절반 폭에 이름 자리 확보).
- 보드의 긴 안내 문장은 차례 문구의 접근성 이름으로, 내 말 `설명` 버튼은 행동 줄로(상단에 자리가 없음).
- 설명 창은 탭 없이 한 장. 손그림의 빈 ★★★ · ★★★★ 줄은 자리 예시 — 가진 스킬만 표시.
- 손그림 과녁 칸 = **치명타**. `+10%p` 칸 = 상태 부여 확률(0이면 칸 없음). `최대♥ +10%` 칸 = 개인 시너지 — 실제 데이터가 있는 "필드에 살아 있는 내 전설"에만.
- 가방 창의 텔레포트 · 도망 · 강제 전투 안내와 추측 메모 목록은 빨간 X 밖이므로 유지.
