## 1. 14~17번 최종 결정

**14 — 왕국 = 같은 속성인 말만 / 아키타입 = 모든 하수인.** 왕국 수혜자 규칙은 현행과 이미 일치해 변경 없음. 아키타입은 "그 아키타입 하수인에게만" → 참전한 **모든 하수인**(일반 30 + 전설 3, 대리 출전 포함)이 자기 타입과 무관하게 활성화된 모든 아키타입 효과를 받는다. 왕·동료 본체 제외는 **좁은 해석**(9.1에 [미확정]). "최고 단계 1개"는 아키타입별로 각각 적용하고, 기존 합산 상한을 그대로 쓴다(새 상한 없음).

**15 — 전설 스탯 > 같은 아키타입 일반 ⭐4.** ⭐4 = ❤️×1.45 / 💪🏻×1.30으로 대조한 결과, 기존 전설 3종은 **일부 스탯이 대응 아키타입의 일반 ⭐4보다 낮았다**(용은 ❤️·💪🏻이 이미 위였고 🏃🏻·💨이 아래, 마녀·사신은 ❤️ 등이 아래).

| | 표준형 ⭐4 → 용 | 지속형 ⭐4 → 마녀 | 공격형 ⭐4 → 사신 |
|---|---|---|---|
| ❤️ | 145 → **175** (현행 150) | 138 → **165** (현행 120) | 131 → **158** (현행 110) |
| 💪🏻 | 29 → **35** (현행 30) | 26 → **32** (현행 27) | 33 → **40** (현행 31) |
| 나머지 5스탯 | 15 / 11 / 5% / 10% / +0%p | 12 / 13 / 10% / 5% / +25%p | 8 / 14 / 15% / 20% / +0%p |

21개 값 전부 신규 제안이며 본문 3.6에 `[제안 · 검증 전]`을 **1회**만 표시(⑮ 행·9.2에서 참조). 스킬 위력·⌛·고유 패시브는 손대지 않았다.

**16 — 경기 시작 상점에서 아이템·전투 버프 구매.** **아이템 5종 전부**(회복약·쿨링수·해독제·몬스터 볼·시너지 교체 티켓) + **전투 버프 3종 전부**, 각 🪙1. 임의로 볼·티켓만 잠그지 않았다. 지급은 여전히 0개. 예비 규칙은 신규 로직 없이 기존 "칸을 채우지 않는 지출은 지출 후 🪙 ≥ 빈 칸 수"가 그대로 적용된다 — 🪙10·빈 칸 6이면 하수인 외 지출 최대 🪙4, 자동 구매로 6칸을 항상 채울 수 있어 잔액 음수 불가. 진열은 ⭐1·미보유 5칸 + 무료 즉시 보충 유지.

**17 — 전설 집계·아키타입·최대 단계·왕국 6종.** 용=표준형 / 마녀=지속형 / 사신=공격형. 전설은 필드든 가방이든 자기 아키타입으로 1 집계되고 왕국은 계속 0(무속성). 살아 있는 개체는 **한 번만** 센다(필드+가방+대리 이중 집계 없음). 필드 전설 사망은 현행 동결 규칙대로 그 아키타입으로 동결, 가방 전설이 대리 패배로 제거되면 집계에서 빠진다. 최대 단계 표준·공격·지속 (6) / 방어·속공·보호 (5)는 **최고 "활성 단계"이지 집계 수 상한이 아니다** — 사망 칸 동결과 같은 종 재구매로 집계 수는 더 커질 수 있고 그때는 정의된 최고 단계가 적용된다(동결·재구매 승인 규칙 무수정). 로스터는 5속성 × 6아키타입 = **일반 30종**, 스킬 **120 + 12**.
전설 고유 패시브는 17번이 언급하지 않았으므로 **직접 참전 시에만** 적용(9.1에 [미확정]).
