## PD 정정 반영

종전 검토의 "모달에 가려진 동안은 보낼 수 없음" 예외를 **삭제**했다. 여는 버튼은 상점 · 전투 · 결과 모달 위에서도 닿아야 하고, 행동 버튼과 중요 HUD를 가리지 않아야 한다.

## 설계 보완 (Venus 기본값 · CJ 결정 아님 · 바꿀 수 있음)

- 버튼 1개(💬 '이모티콘' · 44px 이상)를 화면 오른쪽 위 안전 영역에 고정한다. 층 순서는 모달 · scrim · 승패 배너 **위**, X01 · X03 **아래**. 모달의 Tab 순환에 이 버튼을 포함한다.
- 팝오버: 6개 버튼 + 숨기기 토글. 화면을 어둡게 하거나 게임 입력을 잠그지 않는다. Esc · 바깥 누르기 · 전송 뒤 닫히고 포커스는 여는 버튼으로. Esc는 팝오버만 닫는다.
- 말풍선: 버튼 바로 아래 오른쪽 정렬(상대 위 · 나 아래) · 누름 통과. 같은 쪽 새 이모티콘은 이전 것을 바꿔 끼운다. 행동 버튼 · 타이머 · HP · 재화 · 상점/가방 카드에 겹치면 그 화면에서 Mars가 옮긴다.
- 연출: 등장 0.3초 → 정지 → 0.2초 사라짐(합계 2.5초 표시 안). 동작 줄이기면 불투명도만 100ms.
- 쿨다운: 버튼에 남은 초 표시 · 비활성. 서버가 준 값으로 센다. 거부된 전송은 쿨다운을 쓰지 않는다. 같은 좌석은 새로고침 · 재접속 뒤에도 이어진다.
- 읽어 주기: 받은 것은 화면 밖 `aria-live="polite"`로 '상대: 좋은 수예요'. 숨김 중이면 말풍선 · 읽어 주기 모두 없음, 숨긴 동안 온 것은 나중에 보이지 않음. 저장 실패 시 기본값 '보임'.

## 구현 메모 (CJ 결정 아님 · 확정 전 대조 필요)

Jupiter와 Mars가 현행 `epoch` · `seatToken`/`tokenGen` · 연결 펜싱(`connGen` · `E_SUPERSEDED`) · 오류 프레임 순서를 **먼저 대조한 뒤** 명령 이름 · 오류 코드 · 프레임 모양을 확정한다. 변하지 않는 조건:

- 전용 일시 이벤트다. 게임 action · `revision` · 이벤트 순번 · 재접속 복원/다시 보기 · 모달 · 상점 번호 · 타이머를 **바꾸지 않는다.** `room_state`에 넣지 않고 저장 · 재전송하지 않는다.
- 서버가 허용 ID · 방 단계 · 상대 연결 · 단절 정지 · 좌석별 5초를 검사한다. 프레임에는 좌석 · ID · 쿨다운만 싣는다.
- 서버 목록과 화면 목록의 6개 ID가 같은지 테스트로 확인한다(공유 모듈 신설 대신).
- **PD 기술 기본값 (2026-09-27 wire 대조 후 · CJ 결정 아님)** — 수신 프레임 `emote`(`from` · `epoch` · `roomId`), 보낸 쪽 결과는 전용 `emote_result`(게임 순번 없음), 보낸 쪽 `cooldownMs` 5000, 재접속 복원 시 `emoteRetryMs`, 전송 가능 여부는 공개 `peerConnected` 연결 상태로 판정.
