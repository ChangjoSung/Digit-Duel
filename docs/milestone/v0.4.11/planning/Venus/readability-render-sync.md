## 1. 우선순위 (1) — GDD-23 오류 보정

### 1-1. §2.2 S01 흐름도 — 시간 초과 갈래에 배치 90초를 중복으로 걸던 문제

종전 흐름도는 `E(자동 구매·자동 배치) → D(S01 닫힘) → F(배치 단계 · 배치 90초 시작)`이라, **자동 배치가 끝난 좌석까지 배치 90초를 다시 받는 것처럼** 읽혔다. 본문 불릿은 이미 "중복 실행하지 않는다"였으므로 그림과 본문이 어긋나 있었다.

치환 후:

| 갈래 | 결과 |
| --- | --- |
| 90초 안에 6칸을 채우고 직접 '완료' | S01 닫힘(말은 아직 배치 전) → **이 좌석에만 배치 90초 시작** → 준비 |
| 90초 만료 | 서버가 ① 남은 칸을 노출 6칸에서 자동 구매 ② 모든 말을 합법 위치에 자동 배치 → **배치 90초를 걸지 않음(중복 자동 배치 없음)** → 준비 |

같은 취지로 함께 맞춘 문장:
- §2.2 "배치 90초는 별개 타이머이고, 두 갈래에 똑같이 걸리지 않습니다" 불릿
- §2.4 타이머 4종 불릿의 배치 90초 괄호 → "이 타이머를 걸지 않음"
- §2.4 "배치 90초 — … 시작합니다" 불릿에 예외 명시
- §9장 V4 행에 같은 예외 반영
- GDD-24 00.4 S02 행도 같은 문구로 통일 — **다만 이때는 00.4만 고쳤다.** 같은 규칙을 적은 00.2 타이머 행과 01절 S02 행은 "중복 없음"·"중복 실행 없음" 표현이 남아 있었고, 아래 7장에서 뒤늦게 맞췄다.

### 1-2. §2.4 — 행동 30초 정지 규칙과 Q2(출전 선택 제한 시간)의 구분

종전 "전투가 진행되는 동안 행동 30초가 멈춘다"는, Q2 선택지 (A)("행동 30초가 출전 선택까지 덮는다")와 서로 모순되게 읽혔다.

치환 후:
- 정지 규칙은 **"전투 판정과 연출이 도는 동안(양쪽이 출전할 말을 이미 고른 뒤 라운드가 진행되는 구간)"**으로 한정.
- 새 불릿: **출전할 말을 고르는 화면은 이 정지 규칙에 들어가지 않는다.** Q2가 (A)면 고르는 동안에도 30초가 계속 흐르고, (B)면 전용 20초, (C)면 제한 시간 없음. 어느 쪽이든 "고른 뒤의 판정·연출 동안 정지"는 그대로.
- Q2 절 끝에 같은 취지의 포인터 문장 추가, §9장 V4 행에도 반영.

**Q2는 결정하지 않았다.** 선택지 A·B·C와 Venus 권고(A)는 그대로 두고 `[CJ 결정 필요]` 유지.

## 2. 우선순위 (2) — Render Free-first 동기화

GDD-23 §9장과 GDD-13 §9장에 **후속(대체) 행**을 새로 추가했다. 기존 2026-09-25 #264 "유료 전환·Dashboard 보고 게이트" 행은 **삭제하지 않고 그대로 보존**했고, 대체되는 것은 "유료 전환이 먼저"라는 **순서뿐**임을 행 안에 명시했다.

새 행에 적은 내용:

| 항목 | 내용 | 구분 |
| --- | --- | --- |
| 무료로도 QA 가능 | 계정·DB의 **제한적인 HTML QA**는 Render 무료 Web + 무료 Postgres 수준에서도 충분 | 확정(CJ Comment · PD 전달 · #264 기록) |
| 유료 선행 불필요 | **구현 착수 전에 유료 요금제로 올릴 필요가 없다** | 확정 |
| 자원 생성은 별개 | **Render 서비스·DB 생성과 결제·요금제 변경은 여전히 미승인**, CJ 별도 지시 전 미실행 | 확정 |
| 무료 Postgres 한계 | 저장 1GB · 생성 30일 뒤 만료(+14일 유예) · 관리형 백업 없음 → 보존 데이터는 수동 `pg_dump` | 확정 |
| 현재 Dashboard 상태 | 실제 요금제 · DB 존재 · 리전 **미확인** — `render.yaml`만으로 단정하지 않음 | 미확정 |
| 유료·백업 선택 시점 | 실계정 **장기 공개 운영 전**에 CJ가 고름 | 확정 |
| 인메모리 경기 | 유료로 올려도 프로세스 재시작 뒤 복원되지 않음(앞 행 그대로 유지) | 확정 |

GDD-23 §2.4 본문에도 같은 내용을 3개 불릿(무료로도 QA 가능 / 자원 생성은 미승인 / 무료 Postgres 한계)으로 반영했다.

**GDD-13 보존 확인:** 1~8장의 v0.4.10 출시 서술과 §7 callout, 그리고 이전 #264 행은 손대지 않았다. 갱신한 것은 9장에 후속 행 1개 추가 + 운영 이력 1줄 + Summary 속성뿐이다.

**PD QA 반영(최종):** 초안의 "먼저 무료로 만든다"는 자원 생성 승인으로 읽힐 수 있어 **"무료 요금제로도 QA 가능 · 유료 선행 불필요"**로 치환하고, "자원 생성·결제·요금제 변경은 미승인" 문장을 GDD-23·GDD-13 양쪽에 명시했다.

## 3. 우선순위 (3) — GDD-24 가독성

### 3-1. §00.2 — 화면 ID 범례 + 평이한 그룹 제목
- 표 앞에 **한 화면 분량 범례** 추가: `T` 타이틀 · `L` 경기 밖(로비·방) · `S` 경기의 큰 단계 · `M` 상점/가방 안쪽 · `B` 전투 · `Y` 서버·엔진 처리(녹색 상자) · `D` 갈림길 · `X` 예외 화면. "번호는 순서가 아니라 주소" 한 줄 포함.
- 한 덩어리였던 표를 **① 스케치 첫 장 — 경기 밖(타이틀·로그인·로비·방·싱글)** / **② 스케치 둘째 장 — 경기 안(시작 상점 → 배치 → 보드·전투 → 결과)** 두 표로 분리. **행 내용·순서는 그대로**이고 흐름을 새로 만들지 않았다.

### 3-2. §00.5 — 한 줄 요약 + 용어 풀이 + 표 읽는 법
- "무엇이 진짜인지는 서버가 정하고, 화면은 보여 주기만 한다" 한 줄 요약.
- **낙관적 표시**를 "먼저 성공한 것처럼 보여 주고 나중에 되돌리는 방식"으로 풀고, 쓰지 않는 이유(되돌리는 화면이 상대에게 정보가 됨 · 재화 계산 어긋남)를 한 문장으로.
- "표 읽는 법 — '주인'은 그 값의 정답을 누가 쥐고 있느냐" 추가.
- 핫시트를 **제거된 경로**로 명시(오프라인 경로 = PVE, 그리고 제거된 핫시트).

### 3-3. §00.4 — PD 추가 지시 반영
독자용 표 셀(S01 뒤로/시간 초과/연결 끊김, S02 시간 초과, S03 연결 끊김)을 **화면에서 보이는 동작 1~2문장**으로 줄이고, 코드 경로·현행 서버 차이·근거·구현 상태를 표 아래 **보충 ①~④**로 옮겼다. `[확정]`/`[CJ 결정 필요]` 표기, 모든 규칙, `[이력]` 문장은 보존했다.

### 3-4. 용어 (PD 추가 지시 반영)
- **읽는 방법** 절에 한 줄: 멀티 = 인터넷 1대1, 핫시트 = 한 기기를 넘겨 가며 둘이, PVE = 사람 대 AI. **2026-09-25 CJ 결정으로 플레이 경로는 멀티 하나뿐**(핫시트 제거 · PVE 잠금)이며 **아래 핫시트·PVE 서술은 이력으로 읽는다**고 최신 결정과 역사 설명을 구분.
- 00절 제목의 **Lerp**를 한 줄로 풀이(CJ 스케치 표기 그대로 · "두 값 사이를 부드럽게 잇는다" → 화면 사이의 이음새, 전환 속도는 00.6).

### 3-5. GDD-23 §8.1 동그라미 번호 (안전 범위 내에서만)
번호를 **다시 매기지 않았다**(다른 절이 "8.1 ③", "8.1 ㉕"로 인용). 표 앞에 한 줄 범례("동그라미 번호는 고정 이름표이고 중요도 순서가 아닌 주소")를 붙이고 열 머리글 `#` → `번호`로 바꿨다. 상세 규칙 문장은 그대로.

## 6. 남은 가독성 핫스팟 (다음 차례 후보 · 이번 범위 밖)
1. **GDD-23 §8.1** — 25개 이상 행이 한 표에 있고 각 행이 여러 규칙을 겹쳐 담고 있다. 번호가 외부 인용 주소라 재배열이 위험하므로, 표를 바꾸지 말고 **"무엇이 바뀌나" 요약 5~7줄**을 표 앞에 두는 방식이 안전하다.
2. **GDD-23 §9장 Decision Log** — 행 하나가 문단 하나 길이다. 날짜별 그룹 소제목과 "대체됨" 표시를 열로 빼면 읽기 쉬워지나 인용 경로에 영향이 있는지 먼저 확인이 필요하다.
3. **GDD-24 §00.6 모션 사양** — `easing`·`ease-out`·`scrim`은 이미 풀이가 있으나 수치 표가 길다. CJ 독자용 요약 3줄 + 상세 표 분리가 후보.
4. **GDD-24 §00.8 범위 판정** — 만들 것/잠글 것/만들지 않을 것이 한 표에 섞여 있어 세 덩어리로 나누면 한눈에 읽힌다.
5. **GDD-23 §5~6 (시너지·로스터)** — 이번 범위 밖이라 손대지 않았다. 표가 많고 용어 밀도가 높아 첫 사용 정의가 더 필요하다.

### 7-2. 이번에 고친 것 3군데

1. `notion-fetch`로 GDD-13(2026-09-25T01:22Z) · GDD-23 · GDD-24 전문을 내려받았다.
