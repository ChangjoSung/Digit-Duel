## 중요한 시스템 주석

### 상점·초기 구성

- 초기 10코인·아이템/전투버프/볼 0·하수인 6명 필수는 CJ 수정. 시작상점 절차·별1 미보유 보장·무료 보충·예비 코인·속성 무료선택/자동선택은 원문 제안이다. 상품 5개가 세로행이고 6명을 살 때 새로 고침이 필요하지 않다. 6명만 사면 6코인 지출·4코인 잔액.
- 자동 구매 `왼쪽 칸`은 **진열 순번 ①부터(화면 위에서부터)**로 시각화한다. Mercury가 `msg_107032f5b784` 후속 ask 응답에서 승인한 문구 대응이며 게임 규칙 신설이 아니다. Venus 게시 시 원문 표현을 진열순번으로 정리 예정.
- 정기 진열은 20턴 ★1~2 / 40턴 ★2~3 / 60턴 ★3~4 / 80턴 ★4~5. 낮은 등급60%·높은 등급40%는 제안·검증 전. 전설 ★5는 3종 중 하나. 개인 진열, 공유 풀 없음, 같은 진열 동종 중복 없음. 다른 등급 재추첨 뒤도 후보가 없으면 빈칸이다.
- 동종 제한은 생존 필드+가방만 센다. 사망 칸의 종은 다시 살 수 있지만 그 사망 칸을 채울 수는 없다. 필드6/가방3/상품5는 각각 별개의 슬롯이다.
- 승급은 독립 전직 버튼이 아니라 상품 구매에서 실행된다. 동급은 정가 합성, 상위 진열은 등급 가격 차액. 최대 등급은 미진열. 승급 제자리 적용, 새 최대 HP 회복, 새 스킬 해금. HP 회복은 원문의 충돌판단 권고로 표시한다.
- 판매가는 누적 실제 지불액100%라는 원장 정의 제안이다. 예: ★2 정가2+동급 합성2=★3 누적4, 판매가4. 새로 고침 비용은 원장에 포함되지 않는다. 포획 원장0, 이후 승급 지출만 누적. 전설10.
- 판매 종은 같은 오픈에서 진열/재구매 잠금, 이미 진열된 행도 판매함 잠금. 다음 오픈에서 재구매하면 판매 당시 HP 비율을 새 최대 HP에 곱해 반올림. 이후 정상 승급은 풀 회복. 이 리필 방지책은 원문 제안이며 실제 밸런스 검증 완료가 아니다.
- 교체는 상점 내 생존 필드 하수인↔가방 1:1. HP 회복 없음, 가방 HP 동결. 사망칸은 속성/아키타입 동결 집계, 교체/티켓 불가. 전설칸은 시너지0. 가방은 집계 제외.

### 시간·비공개·온라인

- 온라인/PVE 동시90초, 양측 완료 또는90초 후 함께 닫힘. PVE AI는 즉시 처리·공정 관측. 핫시트는 1인60초 순차(원문 제안), 첫 오픈 P1→가림→P2, 이후 오픈마다 선이용자 교대. 가방3칸은 소유자 화면에 항상 표시되며 상대 화면에 내용뿐 아니라 개수도 노출하지 않는다.
- 비공개: 재화·등급·미사용 스킬·시너지 정확 집계/단계·가방·원장·판매 기록·포획 선택. 상대는 중립 상점 이용 문구와 교체 표식만 본다. 기공개 말은 가방을 거쳐도 공개 유지, 공개 자리로 들어온 비공개 말은 교체 표식만 표시한다. 전투 상대 칩을 그리지 않으며 발동한 효과만 상태/로그에 보인다.
- 기술 변수는 제품 화면 문구에 넣지 않는다. 시스템 주석에만 온라인 요청ID·진열번호·중복1회 처리·지난 진열 거부·서버시각 마감·원자적 반영을 기록한다. 온라인 확인 승인은 요청, 서버 수락이 확정이다. 핫시트/PVE는 승인 순간 확정이다.
- 마감은 확정 변경 유지/미확정 입력 취소. 연결이 끊겨도 새 유예초를 만들지 않는다. 재연결 시 수락분 복구, 이미 닫힌 상점 재개방 금지. 수락 거래 유지→몰수 판정→경기 종료, 몰수 확정 뒤 도착한 거래 처리 안 함.

### 전투·포획

- 대리 승리 시 HP 유지하여 가방 복귀. 패배하면 대리 제거, 왕 대리면 경기 패배, 동료 대리면 해당 동료도 제거. **그 손실을 D24 판정 전에 계산**한다. Y25는 판정 후 자산/표시 정리이며 패배 판정을 늦추는 별도 단계가 아니다.
- 전투 종료는 HP만 유지하고 상태이상·버프·방어막·쿨타임 초기화. 도망 성공도 이 새 쿨타임 초기화 규칙을 적용한다. 사망/포획된 말의 제거는 당연히 유지된다.
- 포획은 적 일반 하수인HP<30%, 볼 보유, 라운드1회, 성공률70%. 왕·동료 본체/전설/내 생존필드·가방 동종 제외는 원문 제안. 대상 비활성 이유는 소유자만 본다. 포획은 등급·스킬 승계, HP70%, 원장0·쿨0. 포획당한 칸은 사망처럼 동결·전멸 판정에 포함(제안).
- 가방초과는 경기 계속일 때만 소유자에게4택1·20초. 핫시트의 현재 화면 소유자가 다르면 B03 가림을 먼저 띄운다. 기존 말 선택 시 그 개체 원장 환급, 포획한 말 선택 시0. 20초 무응답은 포획한 말만 내보낸다. 포획으로 왕 대리 패배·전멸 등 경기 승패 확정 시 선택창 생략.
- 도망 기본30%, 수호자70%, 실패 페널티 기본 공격은 스킬/시너지 발동이 아니다. 실패 후 상대 정상 차례 유지. 성공 후 후방 교환 선택·생략·밀기/접촉은 GDD13 현행. 뿌리 고정 등 도망 금지 상태는 버튼 비활성. 본체 기본기·새 스킬 체계는 GDD23을 따른다.

## 미확정 / 확인 사항

1. 원문 제안 전반(시작 절차·무료 속성/자동선택·진열 확률·원장/리필·포획 제외/20초·온라인 거래 권위)과 승급HP 충돌판단의 최종 승인·구현 검증은 아직 아니다. 이 문서는 검토 가능한 시각안이다.
2. 출전 순차 블라인드의 공격자/방어자 상세 선택순·미확정 선택 취소의 정확한 버튼 계약은 GDD23에 별도 정의가 없다. 현행 순서 유지로 표시하며 새로운 전투취소 버튼·선택 타이머를 만들지 않았다.
3. 가방 초과 선택 중 연결이 끊기는 경우의 타이머 정지 여부·복귀 시 남은 초 계산은 명시가 없어 결정하지 않았다. 기존 재연결/몰수 원칙은 유지하며 Jupiter/Venus 계약 확인 필요.
4. 완료 후 다시 상점 편집 가능 여부·일반 새상품 확인 모달 유무·상점 닫힌 시간의 상점 아이콘 클릭 표현은 원문이 세밀히 정하지 않았다. 시트는 필수 확인(승급·판매·티켓)을 보이고 완료 후 대기로 표시한다. 추가 규칙을 확정하지 않는다.
5. 초기 자동구매 행순서 표현은 Mercury 응답으로 해소. 서버 기술변수는 시스템 lane에만 배치했으며 와이어프레임에는 자연어 상태만 둔다.
