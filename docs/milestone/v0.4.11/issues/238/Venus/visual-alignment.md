## 1. 모든 화면 공통 (수용 기준)

1. **세로 모바일 한 화면**(320·360·390·432px). 가로 스크롤 0, 누를 칸 44px 이상.
2. **아이콘 먼저, 글자 최소**: 버튼·상태는 아이콘 + 숫자 또는 2~6자 짧은 라벨. 긴 설명 문장은 화면에 펼치지 않고 `?` 도움말·툴팁·`<details>`에 접는다. 모든 아이콘 버튼은 접근성 이름(`aria-label`)을 그대로 가진다.
3. **잠긴 기능은 잠긴 채**: 스케치의 🔒 항목은 🔒 배지 아이콘 + 누르면 "추후 공개" **상단 Toast**가 잠깐 뜨고 사라진다(최신 1 · [현행] Toast 모양 · 기본 2300ms 재사용, 로비는 미션 줄 아래 로비 전용 자리). 화면에 고정으로 남는 잠금 문구는 두지 않는다. 실제 오류·입력 검증 안내는 [현행] 자리 그대로. 기능·API·저장값을 새로 만들지 않는다.
4. **이력 토글 제거**(5절). 서버의 공식 전적·경기 데이터는 그대로 둔다 — 지우는 것은 화면 컨트롤뿐이다.
5. 계정·세션·닉네임·DB·게임 규칙·서버 계약은 바꾸지 않는다. 입력 검증·오류 문구·단절 잠금·비공개 경계는 줄이지 않는다.
6. 전투 화면(B04) 배치는 **공용 CSS 변경으로 우연히 바뀌지 않게** 선택자를 화면 단위로 가둔다.
