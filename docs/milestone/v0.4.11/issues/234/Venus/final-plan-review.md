## 1. 번개 꼬리 — CJ 설계 구현 기본값

### 1.1 CJ 문장을 규칙으로 옮기면 [추론]

> 스킬의 사용 순간 데미지를 입힌 뒤 이후 턴이 넘어가지 않고, 이번 턴만 모든 쿨타임 디버프를 제외한 뒤 2차, 3차 스킬의 ⌛0이 되고, 스킬 데미지가 기존 데미지의 60%지만 한번 더 공격이 가능합니다. 이후 턴 종료가 되면서 원래 ⌛으로 돌아온 뒤 쿨타임 디버프도 이때 다시 적용시킵니다.

비유하면 **보너스 행동권 한 장**이다. 한 번 더 치되 60% 세기로만 치고, 끝나면 라켓 상태(⌛)를 원래대로 돌려놓는다.

```
번개 꼬리 사용 (⌛4 설정)
  └─ 💪🏻 100% 타격
  └─ [보너스 시작] 2·3차 ⌛ 사본 저장 → 2·3차 ⌛ = 0
       └─ 같은 플레이어가 다시 고름: 스파크 스침 / 전광석화 / 기본기 (피해 60%)
       └─ 도망 · 볼 · 아이템 · 패스 불가
  └─ [보너스 끝 = 번개 여우의 턴 끝] 2·3차 ⌛를 사본으로 되돌림 (디버프로 늘어난 몫도 함께 돌아옴)
  └─ 상대 행동 → 라운드 종료 ⌛ −1
```

CJ 문장이 이미 정한 것: 선택 주체는 플레이어("턴이 넘어가지 않고 … 한번 더 공격") → Mars 방식 A. 추가 공격에 쓴 스킬도 "원래 ⌛으로" → 사용 전 값 복원. 디버프 "이때 다시 적용" → ⌛ 사본 복원과 수치가 같다(추가 공격 동안 상대가 행동하지 않아 새 디버프가 생기지 않는다 · Mars_2 1.3).

### 1.4 수치 밸런스 — 한 턴 두 번 공격

**한 턴 기대 피해 = 💪🏻 × (100% + 60% × 추가 공격 위력).** 회피 · 치명은 타격마다 따로 굴리므로 기대값은 합과 같고 흔들림만 줄어든다. 번개 여우 ⭐4 💪🏻 = 24 × 1.3 = 31.2.

| 추가 공격 | 합계 위력 | 방어 전 피해 |
|---|---|---|
| 스파크 스침 120% → 72% | **172%** | 53.7 |
| 기본기 100% → 60% | 160% | 49.9 |
| 전광석화 70% → 42% (+ 번개 꼬리 ⌛ −1) | 142% | 44.3 |

같은 ⭐4 · 4차 (💪🏻 = 아키타입 기본 × 1.3, 방어 전):

| 4차 | 아키타입(💪🏻) | 위력 | 피해 | 조건 · ⌛ |
|---|---|---|---|---|
| **번개 꼬리(CJ)** | 속공(31.2) | **172%**(2타) | **53.7** | 없음 · ⌛4 |
| 꺼지지 않는 불티 | 속공(31.2) | 130% | 40.6 | 화상 연장 · 선턴 효과 · ⌛3 |
| 심연의 일격 | 공격(32.5) | 150 / 250% | 48.8 / 81.3 | 약화 소모 · ⌛4 |
| 천둥 낙인 | 공격(32.5) | 130 / 260% | 42.3 / 84.5 | 대상 후턴 · ⌛4 |
| 포식 | 공격(32.5) | 160 / 260% | 52.0 / 84.5 | HP 30% 이하 · ⌛4 |
| 대지 관통 | 공격(32.5) | 180% | 58.5 | 방어 무시 · ⌛4 |
| 연쇄 번개 | 표준(28.6) | 100~220% | 28.6~62.9 | 감전 누적 · ⌛4 |
| 지하 매복 | 표준(28.6) | 230% | 65.8 | 굴 파기 다음 라운드 · ⌛4 |

- 172%는 **조건 없는 4차의 중간값**. 번개 꼬리가 그 라운드에 더하는 몫은 **+52%p**(원래 스파크 스침 120%를 쳤을 것이므로).
- 6라운드 순수 위력 합: ⭐3(번개 꼬리 없음) **720%** · ⭐4 정석(R1 · R5 번개 꼬리 + 스파크 스침) **824%**(+14%, 현행 GDD 문구와 같은 값) · 전광석화로 번개 꼬리 3회 **686%** · 전광석화 추가 2회 + 나머지 스파크 스침 **764%**.
- **결론: 위력 천장은 그대로, 밸런스 위험 낮음.** 두 번 나눠 치므로 과부하(타격당 상한) · 철벽(1회 무효)에 조금 강하고 반사 · 약화에 조금 약하다. 교대 방식에서 천둥 낙인이 늘 260%가 될 수 있는 점(5.4)과 비교하면 오히려 "4차치고 체감이 작다"가 관찰 포인트다.

## 2. 해일 예고 — CJ 확정안과 남은 기본값

### 2.1 CJ 확정 내용 [결정됨]

> 💪🏻 (120% + 대상 약화 남은 횟수 × 30%)로 데미지를 예약해 둔 뒤, 매 라운드마다 남은 HP와 해당 데미지를 계산해서 이 데미지로 HP가 0 이하가 된다면 그때 해일 예고 스킬 Effect가 발동되면서 사망. 내 라운드 · 상대 라운드 둘 다 발동될 수 있기 때문에 매 턴마다 체크.

3차 확정: ① 예약 피해는 **사용할 때 확정**, 난수 단계도 **그때 계산** ② UI로 **다가오는 피해**를 보여 준다 ③ **방어막은 HP와 합산**해도 죽는 피해면 발동 ④ **천년목 · 철벽 돌파 · 과부하 방벽은 발동 순간에는 막지 못하고, 그 효과가 끝났을 때 죽는 피해면 사망**.

비유하면 **증권의 손절매 주문**이다. 주문을 넣는 순간 기준가 X가 정해지고, (HP + 방어막)이 X에 닿으면 자동 체결된다. 방어 효과는 **거래 정지**처럼 체결을 미룰 뿐, 풀리면 다시 조건을 본다.

```
사용 순간: ① 회피 판정 → ②~⑩ 계산(분산 · 상성 · 가하는 피해 · 약화 · 치명 · 방어력 · 균열 · 반올림) → X 확정 · 표식
매 행동 뒤 / 라운드 종료 처리 뒤 / 방어 효과 만료 뒤:
   HP + 방어막 ≤ X ?
     └ 아니오 → 대기
     └ 예 → 천년목 · 철벽 · 과부하 중 하나라도 켜져 있나?
              └ 예 → 보류(표식 유지, 효과 소모 없음)
              └ 아니오 → 🌊 발동 · 사망(방어막째)
```

**③ ④ 해석** [추론 · 문장 해석]: "막지 못하고 … 끝났을 때 죽는 피해면 사망"을 **"켜져 있는 동안 사망을 미루고, 끝난 뒤 다시 판정한다 · 그 효과는 소모되지 않는다"**로 읽었다. 다른 해석("발동 순간 효과를 한 번 소모시키고 끝나면 사망")도 가능하므로 PD가 CJ 원문과 대조해 주기 바란다.

### 2.4 냉철한 위험 점검

**위험 1 — 사용 순간 회피 = 4차 증발** [추론]

| X 유리(×1.3) | 41 | 51 | 61 | 71 | 81 |

약화 2회 · 중립에서 **방어력까지 반영한 X가 대상 (최대 HP + 기본 방어막)의 몇 %인가** (⭐4, 방어력 ⑧ 적용):

| X≈44 → 36% | X≈44 → 34% | X≈42 → 30% | X≈42 → 29% | X≈42 → **24%** | X≈37 → **21%** |

- 만피 상대에게 쓰면 파도 술사 혼자 선까지 끌어내리는 데 3~4라운드가 걸린다. 최대 6R에서 표식에 1라운드를 쓰면 빠듯하고, 안 맞으면 그 행동은 **피해 0**이다(대신 쳤을 파도의 저주 110% ≈ 29 + 약화를 잃음).

## 5. 속도 — 회피율 감소 전환안 · 1라운드 속도와 교대

### 5.1 배경 — CJ 2차 질문에 대한 판정 [확정]

"속도가 선후 판정 말고 의미가 있나? 속도가 떨어져도 디버프가 없다" — **맞았다.** 규칙이 속도를 읽는 곳은 선턴 판정 1곳뿐이고(회피 · 도망 · 피해 · 아이템 · AI · 승패 판정은 속도를 보지 않음), 속도 감소가 순서를 뒤집는 상대는 모래 여우 8.7~12.2% · 용 23.6%뿐이며, 화면에 표시도 없었다(Mars_2 4장). CJ는 3 · 4차에서 속도 감소를 없애고 속도를 1R 선턴에만 쓰도록 정했다.

**사실 정정은 4차 결정으로 대체된다**: 현재 코드는 매 라운드 시작마다 선턴을 다시 정한다(PD 확인, `decideFirstSide`). 4차 결정 뒤에는 1R에만 정하므로, 전투 중 속도 변화가 순서에 영향이 없다는 CJ 전제가 **규칙상 사실이 된다.**

#### 5.2.3 규칙 [제안 · 미확정]

| 항목 | 제안 | 이유 |
|---|---|---|
| **최종 회피율** | **기본 + 회피 증가 합 + 시너지 − 회피율 감소 → 0% 미만은 0, 40% 초과는 40** | 한 식으로 끝난다. "상한을 먼저 자르고 빼기"로 하면 회피를 40% 넘게 쌓은 상대에게 감소가 더 세게 들어가 규칙이 둘이 된다 |
| **부여 방식** | **확정 부여** — 날개 강타 · 모래바람은 **적중 시**, 모래 폭풍은 사용 시(공격 아님) | 현행 속도 감소도 확정 부여다(Mars_2: 날개 강타 `force:true`). 확률로 바꾸면 체감이 더 약해진다 |
| **회피하면** | 날개 강타 · 모래바람이 회피당하면 **감소 없음** | "회피하면 대상 효과 없음" 현행 규칙 |
| **💫 부여 확률 · 모래 폭풍 '확률 절반'과의 조합** | **영향 없음** — 확정 부여는 확률을 굴리지 않으므로 💫 보정도, 모래 폭풍의 절반도 적용되지 않는다 | 모래 폭풍의 절반은 **대상이 거는** 확률 효과에만 걸린다(Mars 구조 분석: 확률 계산 한 곳). 모래 여우끼리 붙어도 서로의 회피율 감소는 확정이라 절반의 대상이 아니다 [추론] |
| **중첩** | 같은 종류 1개 · **큰 수치 · 긴 지속**으로 갱신(5.6) | 모래 폭풍 −20 위에 모래바람 −10이 오면 −20 유지 |
| **분류 · 해제** | **상태이상** — 해독제 · 맑은 물 · 변덕 주문으로 해제, 거울 수면으로 옮기기 가능, 해제 순서표에서 '속도 감소' 자리를 대신함(P2) | 4.5에서 속도 감소가 상태이상이었다 — 자리만 바꾼다 |
| **지속 세기** | 부여 라운드를 세지 않고 다음 라운드부터 2R(5.6) | 현행 속도 감소와 같다 |
| **표시** | 상태 아이콘 추가(예: 💨↓) · 로그 "회피율 −N%" | 속도 감소가 보이지 않았던 문제를 되풀이하지 않는다 |
| **4.5 사전** | "속도 감소 · 회복 감소" 행 → **"회피율 감소 · 회복 감소"** | 속도 감소 상태이상 자체를 사전에서 없앤다(3차 결정 대상에 포함) |

#### 5.2.4 냉철한 효과 평가 [추론 · 계산]

- **기본 회피 0%인 상대(일반 하수인 절반 · 왕 · 방패병)에게는 회피 버프가 없으면 효과 0이다.** 그 상대들 중 회피 버프 스킬을 가진 것은 심해 사냥꾼(잠영 +20%) 1종뿐이고, 나머지는 속공형 시너지를 받았을 때만 감소가 들어간다. 즉 회피율 감소는 **"회피형 카운터"라는 분명한 역할**을 갖는 대신 **범용 디버프는 아니다.**
- 피해 기대값으로 환산(대상 회피 → 감소 후): 10% → 0%: **+11%** · 15% → 0%: **+18%** · 40% → 20%(안개 걸음 켠 속공형에 모래 폭풍): **+33%** · 5% → 0%: +5%.
- 비교: 속도 감소는 대상의 8.7~23.6%에게 "누가 먼저냐"만 바꿨다. 회피율 감소는 **대상의 약 절반(기본 회피 5% 이상 일반 하수인 15종 + 전설 3 + 암살자)에게 매 타격 기대 피해를 +5~33%** 올린다 — **분명히 더 강하고 보인다.**
- **이중 보상 주의**: 모래 폭풍은 "상태이상 운용" + "회피 운용"을 한 스킬로 꺾게 된다. 안개 무희(속공 회피형)가 모래 여우를 만나면 정체성이 크게 눌린다 — 4차 시그니처끼리의 상성으로 허용하되 CJ 플레이 QA 관찰 대상. [추론]
- **해일 예고 회피(2.4 위험 1)와는 연결되지 않는다** — 파도 술사는 회피율 감소를 갖지 않는다.

### 5.3 1라운드 속도 + 교대 방식 [결정됨 + PD 해석 · CJ 확인 중]

**CJ 4차**: "속도는 첫 라운드 선턴 판별만 진행하고, 나머지는 전부 기존 전투 방식대로."

**기존(v0.4.10) 방식** [확정 · dev `654a6e2` `actorOfPhase`]: 홀수 라운드는 접촉을 건 쪽(A)이 먼저, 짝수는 상대(D)가 먼저. 먼저 할 쪽이 감전이면 뒤집는다. 코드상 **양쪽이 모두 감전이면 A가 먼저**다(A 감전 → D로, D 감전 → 다시 A로) — 접촉을 건 쪽에 치우친 동작이다.

**권고 규칙 문장(GDD 4.4 교체안)** [제안 · 미확정 · PD 해석을 문장화]:
1. **1R 선턴** = 4.4 현행 순서 — 순서 효과 분류(선턴 > 기본 > 후턴) → 🏃🏻 속도 → 낮은 ⭐ → 접촉을 건 쪽.
2. **2R부터 교대** — 홀수 라운드는 1R 선턴 쪽, 짝수 라운드는 상대가 **예정 선턴**이다.
3. **그 라운드의 순서 효과 분류가 다르면 분류가 우선**한다(예정 선턴이 감전이고 상대가 기본이면 뒤집힘 · 예정 후턴에게 선턴 효과가 있으면 뒤집힘). **분류가 같으면 예정대로**(양쪽 감전이면 뒤집지 않음 — 기존 코드의 A 치우침을 이번에 바로잡는다). 뒤집혀도 **다음 라운드의 예정은 바뀌지 않는다.**
4. 전투 중 속도 증감은 이 판정에 쓰이지 않는다.

**속도 · 속공형 시너지의 남은 의미** [확정 논리]: 1R 선턴 한 번. 이후 교대이므로 "먼저 행동하는 라운드 수"는 1R 선턴 쪽이 **최대 1라운드 많은 것**(6R 중 3:3, 홀수 라운드 전투 종료 시 한 번 더)뿐이다. **속공형 시너지 속도 +1~+4는 1R 선턴에만 의미가 있다** — GDD 5.4에 주석 필요. 전투 중 속도 증가(충전 +3)는 의미가 없다 → 4.1 #2 수정.
