## 먼저 알아 둘 용어 (짧게)
- **⌛(쿨타임)**: 스킬을 쓴 뒤 자기 행동 N번 동안 다시 못 쓴다. ⌛0 = 매번 사용 가능.
- **R(라운드)**: 전투에서 양쪽이 한 번씩 행동하는 단위. 보드 '턴'과 다르다.
- **선턴 · 후턴**: 한 라운드에서 먼저 / 나중에 행동하는 쪽. **라운드 시작 때 확정**된다(4.4). 감전은 "다음 1라운드 후턴"으로 만드는 상태이상이다.
- **상태이상 vs 버프**(4.5): 상대에게 거는 나쁜 효과(화상 · 약화 · 감전 · 균열 · 속도 감소 · 회복 감소, 이끼 잠식)는 상태이상, 자기에게 거는 좋은 효과(경화 · 흡수 · 방어막 · 회피 증가 · 가하는 피해 증가)는 버프. **해독제는 상태이상만** 푼다.
- **지속 피해**(4.3): 화상처럼 최대 HP %로 들어가는 피해. 방어막 · 방어력 · 회피를 모두 건너뛰고 HP에 바로 들어간다.
- **타격 1회**(4.2): 피해 계산 한 번. 한 스킬이 두 번 때리면 타격 2회다.

## A3. 번개 꼬리 — 이어 쓸 스킬 후보가 둘 이상일 때

**라이브: 아님** — 번개 여우 ⭐4 전용(#236 전 비라이브). 이 스킬을 가진 종은 번개 여우 하나뿐이다.

**(1) 무엇이고 GDD 원문**
- 번개 여우(⚡ 속공형) 4차: "💪🏻 100% 후, **⌛0인 다른 피해 스킬 1개(기본기 제외)**를 위력 · 효과 60%로 이어서 사용. 이어 쓴 스킬의 ⌛는 정상 적용, 없으면 첫 타격만 / ⌛4"
- 한 번 때리고, 쉬고 있는(⌛0) 다른 공격 스킬 하나를 약하게 덤으로 한 번 더 쓰는 스킬이다.

**(2) 비어 있는 지점**
- 후보가 둘 이상이면 **누가 · 무엇을 기준으로 고르는지** 없다. 번개 여우의 후보는 2차 스파크 스침과 3차 전광석화 두 개다.
- 가장 가까운 선례는 4.6 "상대 스킬 ⌛를 늘리는 효과는 **고르는 화면 없이 자동으로** … 같으면 슬롯 순서(2차 → 4차)"다.

**(3) 전투 장면**
- 번개 여우 ⭐4(💪🏻 31)가 1라운드에 번개 꼬리를 쓴다. 모든 스킬이 ⌛0이다.
- 스파크 스침을 이으면: 💪🏻 120% × 60% = **72%** 위력 + 감전 30% × 60% = **18%**.
- 전광석화를 이으면: 💪🏻 70% × 60% = **42%** 위력 + "남은 ⌛가 가장 긴 스킬 ⌛ −1" — 방금 ⌛4가 된 번개 꼬리 자신이 3으로 줄 수 있다 **[추론 · 코드 읽기]**.

**(4) 선택지**
| 선택 | 플레이 체감 | 밸런스 영향 |
|---|---|---|
| ① 자동 · 슬롯 순서(2차 → 3차) | 버튼 한 번. 결과를 예측하기 쉽다 | 번개 여우에게는 사실상 늘 스파크 스침. "위력이 높은 쪽 자동"과 같은 결과 |
| ② 플레이어가 고름 | 팝업이 한 번 더 뜬다. 온라인에서는 입력이 하나 늘고 시간 초과 처리가 필요 | 전광석화로 번개 꼬리 ⌛를 당기는 콤보가 생긴다 |

**(5) 현재 구현**: ① 자동 · 슬롯 순서. ⌛0이면서 사용 조건을 채운 피해 스킬만 후보이고, 사신의 낫은 제외한다. **[확정 · 코드 확인]**

**(6) Venus 권고: ① 현행 유지** — GDD 4.6이 "화면 없이 자동"을 이미 택했다. 후보가 고정된 종 하나뿐이라 선택 화면을 새로 만들 이유가 작다. **[추론]**

**(7) CJ 질문**: 번개 꼬리가 이어 쓸 스킬을 슬롯 순서로 자동 선택(스파크 스침 우선)해도 됩니까?

## A4. 변덕 주문 · 맑은 물 — 무엇부터 지우나

**라이브: 아님** — 변덕 주문은 전설 마녀(#236 전 비라이브), 맑은 물은 물방울 요정 ⭐3.

**(1) 무엇이고 GDD 원문**
- 마녀 3차 변덕 주문: "대상 **버프 1개** 제거 · 자기 **상태이상 1개** 해제 / ⌛3"
- 물방울 요정 3차 맑은 물: "자기 **상태이상 1개** 해제 · 최대 HP 8% 회복 / ⌛3"
- 3.2: 변덕 주문으로 사라진 방어막 층은 "깨짐이 아니며"

**(2) 비어 있는 지점**
- 대상에게 버프가 여러 개 · 상태이상이 여러 개일 때 **어느 1개**를 지우는지 없다.
- 방어막이 여러 층일 때 한 층만 지우는지, 방어막 전체가 "버프 1개"인지도 없다.
- 덧붙여 **[미확정]**: 영겁의 재 화상은 "해독제로 해제되지 않음"이라고만 적혀 있어 맑은 물 · 변덕 주문으로는 풀리는지 문장이 없다.

**(3) 전투 장면**
- 마녀가 변덕 주문을 쓴다. 상대에게 **방어막 20 + 경화 30%**가 함께 있다(예: 시너지 방어막 + 강철 가죽).
- 방어막을 지우면 다음 공격이 HP에 바로 들어가고, 경화를 지우면 방어막 20은 남지만 이후 피해가 30% 커진다.
- 동시에 마녀 자신에게 **화상 + 감전**이 있으면, 화상을 풀면 라운드 끝 피해가 없어지고, 감전을 풀면 다음 라운드 순서를 되찾는다(이번 라운드 순서는 이미 확정이라 안 바뀐다).

**(4) 선택지**
| 선택 | 플레이 체감 | 밸런스 영향 |
|---|---|---|
| ① 고정 순서(현행) | 매번 같은 결과라 배우기 쉽다 | 방어막부터 지워 보호형에 가장 강하게 작동 |
| ② 무작위 1개 | 매번 다르다. 결과를 계획하기 어렵다 | 기대값은 평균적. 난수가 하나 더 든다 |
| ③ 사용자가 고름 | 팝업 추가. 전략성이 높다 | 항상 최선을 골라 스킬이 가장 강해진다 |

**(5) 현재 구현 [확정 · 코드 확인]**
- 버프: 방어막(**전 층을 한 번에**) → 경화 → 흡수 → 회피 증가 → 가하는 피해 증가 → 속도 증가.
- 상태이상: 화상 → 약화 → 감전 → 균열 → 속도 감소 → 회복 감소 → 이끼 잠식.
- 선턴 효과 · 확정 치명 · 굴 파기 · 과부하 · 철벽 · 천년목 · 감전 면역 같은 **스킬 고유 예약 효과는 지우지 않는다**.
- 맑은 물 · 변덕 주문은 영겁의 재 화상도 푼다(해독제만 못 푼다).

**(6) Venus 권고: ① 현행 유지** — 4.5 사전 순서를 그대로 따라 설명이 쉽고, 방어막은 4.5에서 버프 **1종**이며 화면에도 바 1개라 "1개 = 전 층"이 자연스럽다. 영겁의 재는 문장이 해독제만 막으므로 현행(스킬로는 풀림)을 유지한다. **[추론]**

**(7) CJ 질문**: 변덕 주문 · 맑은 물이 GDD 4.5 사전 순서대로(방어막 전 층 먼저 / 화상 먼저) 1개를 자동으로 지우는 방식으로 확정해도 됩니까?

## A5. 영구 자기장 — 감전 재부여가 순서를 언제 묶나

**라이브: 아님** — 전자기 술사 ⭐4 전용.

**(1) 무엇이고 GDD 원문**
- 전자기 술사(⚡ 지속형) 4차: "2R 동안 **매 라운드 시작 시** 대상에게 감전 100% 재부여 / 전투당 1회"
- 5.6: "N 라운드 지속은 **다음 라운드부터** N라운드", "1R 감전은 **부여 라운드의 남은 행동과 다음 1라운드** 동안 유효"
- 4.4: 선턴 · 후턴은 "라운드 시작 시 확정"

**(2) 비어 있는 지점**
- 같은 "라운드 시작" 순간에 **감전 부여**와 **순서 확정** 중 무엇이 먼저인지 없다.
- 먼저 부여하면, 5.6 규칙대로 마지막 감전이 한 라운드 더 남아 **최대 3라운드 연속 후턴**이 된다. 문장대로 계산한 결과지만 체감이 크다.

**(3) 전투 장면 (3라운드에 사용)**
```
R3  영구 자기장 사용 (이번 라운드는 이미 시작 → 부여 없음)
R4  시작: 감전 부여 → 순서 확정 → 상대 후턴
R5  시작: 감전 재부여 → 순서 확정 → 상대 후턴
R6  R5 감전이 아직 유효(5.6 '다음 1라운드') → 상대 후턴
R7  풀림
```
- 순서 확정 **뒤에** 부여하면 R4는 원래 순서 그대로이고 R5 · R6이 후턴 → **2라운드**.

**(4) 선택지**
| 선택 | 플레이 체감 | 밸런스 영향 |
|---|---|---|

## B2. 균사 전환 '2R 동안 흡수 30%' — 확률인가 회복 비율인가

**라이브: 아님** — 방패 버섯 ⭐4.

**(1) 무엇이고 GDD 원문**
- 방패 버섯(🌿 보호형) 4차 균사 전환: "현재 자기 방어막을 전부 HP 회복으로 전환(최대 HP 30% 한도) · **2R 동안 흡수 30%** / ⌛4"
- 2차 골격 "자신에게 흡수 70%"의 70%는 **확률**이다 **[확정 · Venus Q9]**.

## C1. 사신의 낫 전투 간 봉인 — '다음 전투'를 무엇으로 세나

**라이브: 아님** — 전설 사신(#236 전 비라이브).

**(1) 무엇이고 결정 원문**
- GDD 6.4 사신 4차 사신의 낫: "자기 차례에, 내 HP 비율이 상대보다 낮을 때만 — 방어막을 무시하고 **즉사**(회피 판정 없음) / 봉인형". (GDD 사본은 아직 "6라운드부터"로 적혀 있다.)
- **[결정됨]** CJ 2026-09-17: 절대 판정 즉사 · **4라운드부터** · 전투를 넘는 봉인(사용 → 다음 전투 봉인 → 그다음 전투 해제). Notion GDD-23 반영은 PD가 CJ 확인 뒤 진행한다.

**(2) 비어 있는 지점**
- '다음 전투'를 **그 사신이 참전한 전투**로 셀지, **내 진영의 아무 전투**로 셀지, **보드 전체의 다음 전투**로 셀지 결정문에 없다. PD가 '참전한 전투'로 추론해 구현했다.

**(3) 전투 장면**
```
전투 1  사신(대리 출전)이 사신의 낫으로 즉사 → 봉인 시작
전투 2  내 하수인 A vs 상대 하수인 (사신 불참)
전투 3  내 하수인 B vs 상대 왕 (사신 불참)
전투 4  사신 참전
```
- 참전 기준(현행): 전투 2 · 3은 세지 않음 → **전투 4는 봉인**, 사신의 다음 참전부터 사용 가능.
- 내 진영 / 보드 기준: 전투 2가 봉인 전투로 지나감 → 전투 3에 풀림 → **전투 4에서 바로 다시 사용 가능**. 사신을 한 번만 쉬게 하면 봉인이 공짜로 사라진다.

**(4) 선택지**
| 선택 | 플레이 체감 | 밸런스 영향 |
|---|---|---|
| ① 그 사신의 참전 전투만 셈(현행) | 봉인이 반드시 사신의 전투 1번을 소모시킨다 | 봉인이 뜻대로 작동. 다만 봉인 전투가 1라운드 도망으로 끝나도 1번으로 센다 |
| ② 내 진영의 아무 전투 | 다른 말로 한 번 싸우면 풀림 | 봉인을 피하는 운용이 쉬워 결정의 의도가 약해짐 |
| ③ 보드 전체의 다음 전투 | 상대의 전투로도 풀림 | ②보다 더 약함. 누구의 전투인지 헷갈림 |

**(5) 현재 구현**: ① — 말(전투원) 단위로 기록하고, 그 말이 라운드 전투에 참전할 때만 1씩 줄인다. 밀어내기 · 폭탄 · 함정 접촉은 세지 않는다. 시간의 수호자로 3R이 된 전투도 참전 1번으로 센다. **[확정 · 코드 확인]** 대리 출전일 때 본체와 따로 기록된다(Mars 보고).

**(6) Venus 권고: ① 현행 유지** — "사용 → 봉인 → 해제"라는 결정의 뜻은 '강한 즉사 뒤에 사신이 한 번 쉰다'이고, ②·③은 사신을 가방에 넣어 두기만 해도 봉인이 사라진다. **[추론]**

**(7) CJ 질문**: 사신의 낫 봉인의 '다음 전투'를 "그 사신이 직접 참전하는 다음 전투"로 세는 현행 방식으로 확정해도 됩니까?
