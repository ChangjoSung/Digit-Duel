## #185 정적 테이블 후보

다음은 현 상수·manifest를 분해한 **논리 후보**다. 파일 수나 모든 행 수를 확정한 DB 스키마가 아니다. 분리/결합은 참조와 편집 단위에 맞춰 결정한다.

| 후보 | 내용·키/검증 |
|---|---|
| Element / ElementBeats | 속성 ID, 상성 관계·누락/중복/순환 검증 |
| PieceType / Roster | 말 종류와 20종 로스터, 수치·속성·아트 참조 |
| Archetype / ArchetypeTemplate | 5개 유형과 편성 슬롯; 복합 키·슬롯 수 검증 |
| Skill / SkillEffect | 공개·내부 기술 구분, 허용된 효과 ID·인자형; 임의 문자열 코드 실행 금지 |
| Item / GiftPick / Buff | 아이템·선물 선택·버프; 선택 순서와 추첨 의미 보존 |
| EventKind / MemoOption | 탐색 이벤트·메모 선택지; 공개 정보 규칙 보존 |
| Balance / FxTiming / MetricKey | 규칙 수치·화면 시간·분석 지표를 각각 분리 |
| ArtManifest / StringKo | 안정적 자산 ID·한글 문구와 표시 키; 경로/누락 검증 |

첫 이행은 현재 HTML의 승인 데이터를 추출하고 대조하는 방식으로 수작업 오류를 줄인다. 이후 TSV를 편집 원본으로 삼을 경계와 생성 대상을 명시하여 HTML·TSV를 서로 독립 수정하는 이중 원본을 만들지 않는다. TSV는 UTF-8, 헤더/타입·탭/개행 escaping, 빈값/null, 숫자 문화권, enum/ID/FK, 정렬·중복·결정적 출력·스키마 버전을 정의한다. JavaScript 배열 순서가 추첨 결과에 미치는 영향을 보존한다. 런타임 반사에만 의존하지 않는 AOT 생성·등록과 실패 원인 표시를 포함한다.

| 데이터 수명 | 예시 | 책임 |
|---|---|---|
| 정적 콘텐츠 | 위 테이블·자산 매핑·규칙 버전 | 배포·콘텐츠 검증 |
| 경기 런타임 | 좌표·HP·턴·효과·RNG 상태·공개 여부 | Core/세션; 정적 테이블로 저장하지 않음 |
| 향후 영속 데이터 후보 | 설정·전적·매치 기록·재접속 snapshot | #184 계약 이후 결정; 계정·과금·자동 MongoDB 문서 생성은 이번 승인 범위 아님 |

런타임 상태도 재접속·감사를 위해 서버가 저장할 수 있다. 따라서 “DB에 저장 금지”가 아니라 정적 데이터와 수명·소유권을 구분한다. 원격 이벤트/조회는 관측자에게 공개된 정보만 전달해야 하며 상대 전체 편성을 무조건 배포하는 API는 제안하지 않는다.

## UI Toolkit 판단

**적합성 검증 후보이며 아직 채택하지 않았다.** Unity 6.6 공식 비교표도 runtime은 uGUI를 권장하고 UI Toolkit을 대안으로 둔다. 2D 보드·목록·상태 화면에 사용할 가능성은 있으나 HTML/CSS를 UXML/USS로 그대로 실행할 수는 없다. [공식 UI 비교](https://docs.unity3d.com/6000.6/Documentation/Manual/UI-system-compare.html)

#187의 첫 산출물은 대표 Android APK에서 보드·전투·모달을 연결한 PoC다. 기존 탭/클릭 선택 방식을 보존하고 드래그는 자동으로 새 요구사항에 넣지 않는다. safe area, 작은 세로 화면, 스크롤과 터치 충돌, Android Back, pause/resume, 한글 fallback, 아틀라스와 FX, 로드/해제·메모리·프레임 비용을 측정한다. 기기와 성능 예산은 측정 전에 명시한다. 실패 항목이 있을 때 uGUI 또는 필요한 렌더링 부분만 혼합하는 대안을 비교한다.

색상 이모지 기능은 있으나 지원 폰트·형식과 기기 검증이 필요하다. 운영체제마다 같은 외형을 보장한다고 가정하지 않고 게임 의미를 갖는 기호는 명시적 자산 매핑을 검토한다. [공식 색상 이모지 문서](https://docs.unity3d.com/6000.6/Documentation/Manual/UIE-color-emojis.html)

## CJ에게 보고할 리소스 차이

조사 범위는 추적된 데모·납품 아트다. 사용자 미추적 `art/`는 조사·변경하지 않았다. HTML의 하수인20종 icon/battle/portrait PNG·WebP와 왕/동료 icon/battle이 있으며, Roblox 납품용 UI·보드·상태·속성·행동·FX PNG도 재사용 후보다. 로블록스용 규격이 Unity 최종 규격이라는 뜻은 아니다.

| 확인 대상 | 현재 판단 | 후속 |
|---|---|---|
| Android adaptive 앱 아이콘·스플래시 | 게임 내 아이콘과 별도 패키징 검토 필요 | #187에서 실제 출력 규격·기존 그림 재사용 가능성 확인 |
| 한글 폰트·기호·라이선스 | 웹 시스템 폰트/문자 표시는 모바일 동일 외형을 보장하지 않음 | 글리프·용량·배포 권리 검증 후 부족 목록 |
| UI 상태·9-slice·FX | 기존 PNG/스프라이트시트 재사용 후보 존재 | 크기·피벗·slice·압축·코드 효과 대응표 |
| 튜토리얼 설명 그림·왕/동료 확대 이미지 | 기존 PNG/SVG·전투 그림의 전용 가능성 확인 필요 | 신규10장 등을 먼저 발주하지 않고 화면에서 부족 여부 판단 |
| 사운드 | 조사한 게임 자산에 음원 없음 | 기존 기능 누락이 아닌 추가 범위 결정 사항 |
