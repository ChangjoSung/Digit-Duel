# Roblox 3D 로비 · 테이블 매칭 설계 (Phase 2a, Ref #118)

- CJ Comment 2026-09-09 [결정]: "캐릭터가 맵을 돌아다니면서 움직이고, 서로 상호작용이 가능하고, 책상이 있고 체스판 위에 있는 판을 바라보고 상호작용하면 배치할 수 있고, 같은 판을 2명이 바라보면 그 둘이 매칭돼서 게임할 수 있도록"
- 이 문서: Mars 구현 설계 (**확정** = CJ 원문 / **추론** = 구현 판단 / **[기획 필요]** = CJ·Venus 결정 대기)
- 아트 요청: [earth-lobby-request.md](earth-lobby-request.md)

## 1. 플로우

```
접속 → 로비 스폰 (아바타, 기본 이동/채팅/이모트)
  → 테이블 의자 앞에서 [E] 앉기 → 그 테이블의 A/B 자리 배정 (HUD: "테이블 N · A 자리")
  → 테이블 패널: [배치 완료] (지금은 무작위 배치, Phase 2b 에서 판 위 수동 배치)
  → 맞은편에 상대가 앉고 둘 다 배치 완료 → 그 둘만의 대전 세션 시작 (보드 GUI)
  → 종료 → [닫기] → 앉은 채로 다시 [배치 완료] 하면 재대전
  → 대전 중 자리 떠나기(일어남·퇴장·[자리 떠나기]) = 기권
```

| 항목 | 상태 | 구현 |
|---|---|---|
| 캐릭터가 맵을 돌아다님 | 확정 | Roblox 기본 아바타·이동. 로비 = 바닥·벽·스폰 (`Lobby.luau`) |
| 서로 상호작용 | 확정 (범위는 추론) | 기본 채팅·이모트·플레이어 목록 유지. 캐릭터 간 프롬프트(대전 신청·인사)는 Phase 2b |
| 책상 + 체스판 위의 판 | 확정 | 테이블 4개: 책상·다리·7×13 그리드 판(SurfaceGui)·마주보는 의자 2개·상태 표지(BillboardGui) |
| 판을 바라보고 상호작용 → 배치 | 확정 (배치 방식은 추론) | 의자 ProximityPrompt [E] 앉기 → 테이블 패널 → [배치 완료]. 수동 배치 UI 는 Phase 2b |
| 같은 판을 둘이 보면 매칭 | 확정 | 같은 테이블 A·B 자리에 둘 다 앉고 둘 다 배치 완료 → 세션 시작 (`tableState`) |
| 자리 이탈 = 기권 | 추론 | 대전 중 점프 잠금(`Humanoid Jumping 비활성`), [자리 떠나기]로만 기립 → 기권 |

## 2. 서버 구조

- `src/server/Lobby.luau` — 로비 지오메트리 생성·의자 점유 감지·상태 표지·기립/잠금 유틸. **콜백**: `onSeated(player,id,side)`, `onVacated(player,id,side)`
- `src/server/init.server.luau` — `tableState[id] = {players={A,B}, ready={A,B}, session}` · `seatOf[player]`. 액션 `ready{setup}` / `unready` / `stand` / `ping` + 기존 게임 액션. 세션 시작·종료 시 잠금/해제·표지 갱신·양측 알림(`table` 메시지)
- Phase 1 의 "빠른 매칭(대기 슬롯)"은 제거 — 매칭은 테이블 단위만

## 3. 클라이언트

- 전면 메뉴 제거 → 왼쪽 위 **HUD**(안내·[자리 떠나기]) + 중앙 **테이블 패널**(상대·[배치 완료]/[배치 취소]) + 대전 중 보드 GUI(기존)
- 서버 메시지: `table{tableId,side,opp,myReady,oppReady,inGame}` · `left` · `state` · `reject` · `hello`
- 화면 하단 진단 푸터: client/server 버전·모듈·UI 로드 상태 (팀 테스트 문제 진단용)

## 5. [기획 필요]

- 관전: 다른 플레이어가 판을 볼 때 무엇을 보여줄지 (공개 말만? 전부 가림? 관전 금지?) — 숨은 정보 규칙과 직결
- 재대전 규칙: 종료 후 자리 유지 시 자동으로 배치 단계로 갈지, 상대 동의가 필요한지
- 대전 중 이탈 페널티(기권 처리는 구현됨) 이상의 전적·매너 지표 여부
- 로비 테마·경험 이름 확정 (현재 "Digit Dual", 아트 콘셉트 미정)
