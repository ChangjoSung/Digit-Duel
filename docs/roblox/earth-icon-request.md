## 1. 배경 — 지금 아이콘이 로블록스 기본 이미지다

2026-09-11 실측: 경험 아이콘이 **로블록스 기본 템플릿**(시골 풍경 + ROBLOX 로고)으로 등록돼 있다. 게임과 아무 관련이 없다.

```
아이콘  512×512  →  ⚠️ 로블록스 기본 이미지
썸네일  16:9     →  digit-duel-thumbnail-v1.png (등록 대기)
```

**아이콘이 썸네일보다 먼저 보인다** — 검색 결과·추천 목록·모바일 앱에서 제일 먼저 노출되는 것이 아이콘이고, 썸네일은 게임 페이지에 들어와야 보인다.

**가로 썸네일을 잘라 쓸 수 없다.** 1672×941 을 1:1 로 자르면 양옆 40% 가 날아가 **물 요정과 번개 골렘이 통째로 사라진다.** 정사각형에 맞춰 새로 구성해야 한다.

### 반드시 지킬 것

**① 아주 작게 줄여도 읽혀야 한다.** 아이콘은 목록에서 **50px 안팎**으로 표시된다. 이것이 다른 모든 요구보다 우선한다.
- 주제를 **꽉 채운다.** 썸네일처럼 넓은 배경 풍경을 넣지 않는다
- 캐릭터는 **최대 2체**. 네 마리를 다 넣으면 작은 크기에서 전부 뭉개진다
- 배경은 **파랑 ↔ 빨강 대각 분할** 정도로 단순하게. 숲·유적·안개 같은 디테일은 뺀다

**② 글자를 넣지 않는다.** `Digit-Duel` 워드마크는 512px 에서도 가늘고, 50px 에서는 완전히 뭉개진다. 로블록스가 아이콘 **아래에 게임 이름을 따로 표시**하므로 그림 안에 이름이 또 있을 필요가 없다.
- 예외: 아주 굵은 **모노그램 1~2자**(예: `D`)를 구도의 일부로 쓰는 것은 허용. 판단은 Earth 가 한다

**③ 캐릭터 정체성을 바꾸지 않는다.** 썸네일의 네 캐릭터 중 골라 쓰되 **디자인·색·실루엣을 그대로** 유지한다. 새 캐릭터·사람을 만들지 않는다.

**④ 모서리가 잘린다.** 로블록스는 아이콘을 **둥근 모서리**로 표시한다. 중요한 요소(얼굴·눈)를 네 귀퉁이에 두지 않고 **가운데 원 안**에 들어오게 한다.

**⑤ 금지** — 로블록스 로고·워드마크 · 가짜 UI·버튼·화살표 · 테두리 · 워터마크 · 홍보 배지("NEW"·"UPDATE") · 과장 문구 · 무기·유혈.

### 구도 제안 (Earth 가 조정해도 된다)

이 게임은 **1대1 대결 + 정체 숨기기**다. 그것이 한눈에 보이면 좋다.

- **빨강 새끼 용 ↔ 파랑 물 요정**이 서로 마주 보는 대결 구도. 둘의 얼굴이 화면의 대부분을 차지한다
- 아래쪽에 **물음표 말 1~2개**만 작게 (숨겨진 정체 — 썸네일의 파랑/빨강 말 어휘 그대로). 여섯 개를 다 넣지 않는다
- 배경은 왼쪽 차가운 파랑 · 오른쪽 뜨거운 주황으로 나뉜 단색에 가까운 면

> 더 나은 구도가 있으면 Earth 가 정해도 된다. **50px 에서 읽히는가**가 유일한 판정 기준이다.

## 4. 납품 형식

1. 파일을 `roblox/assets/marketing/` 에 둔다. **`manifest.csv` 에 넣지 않는다** — 게임 런타임 자산이 아니라 경험 메타데이터다 (썸네일과 같은 취급).
2. `docs/art/roblox-v0.5.0/icon-source/README.md` 에 제작 기록(최종 프롬프트·실제 파일 규격·SHA-256)을 남긴다.
3. **축소 검수 이미지**를 함께 낸다 — 같은 아이콘을 **512 / 150 / 100 / 50 px** 로 나란히 둔 시트. 50px 에서 무엇이 보이는지가 이 자산의 합격 기준이다.
4. `worker_done` 보고에 파일·해시·실제 해상도를 적는다. **요청 해상도가 아니라 생성기가 낸 실제 크기**를 적는다 (썸네일이 1920×1080 을 요청했으나 1672×941 이 나온 전례).
