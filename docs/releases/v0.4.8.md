# v0.4.8 — 온라인 대전 아트 로드 수정

2026-09-11 · [Issue #201](https://github.com/ChangjoSung/Digit-Duel/issues/201)

온라인 1vs1 대전에서 왕·동료·일부 하수인의 그림이 이모지나 이름으로 표시되는 문제를 수정합니다. 이미지 요청이 몰릴 때 발생하는 서버의 요청 제한과 클라이언트의 로드 실패 처리를 보완합니다.

## 적용 방법

[GitHub Release](https://github.com/ChangjoSung/Digit-Duel/releases/tag/v0.4.8)의 Source code를 받아 압축을 풀어 주세요. 온라인 서버를 운영한다면 진행 중인 경기를 마친 뒤 기존 서버를 종료하고 새 버전의 `server/LAN서버시작.bat`을 실행하세요. 두 플레이어 모두 새로 열린 서버 주소에서 페이지를 새로고침해야 수정된 클라이언트를 받습니다.

`demo/index.html`과 `demo/assets/`는 함께 두세요. [온라인 실행 안내](../../server/README.md)에 접속 방법이 있습니다.

## 검증 기록

클라이언트 회귀 101건, 기존 CI A의 22개 검사 묶음과 서버 5개 검사 묶음이 통과했습니다. 실제 브라우저 두 접속의 온라인 인증·매칭·아트·합법 이동 동기화 및 일시 실패 복구 등 34건을 확인했습니다. README의 보드·전투 사진도 이 소스로 다시 촬영했습니다.

독립 검수는 [Saturn 기록](../hotfix/201/Mercury/qa.md), 브라우저 결과·소스와 이미지 지문은 [캡처 기록](../hotfix/201/Mars/artifacts/report.json)에 있습니다. 보드는 실제 온라인 대전, 전투 사진은 정상 배치가 완료된 오프라인 검증 장면입니다. 실제 두 기기의 LAN 장기 플레이는 CJ 확인 대상으로 남깁니다. 상대 물음표는 비공개 말의 정상 표시입니다.
