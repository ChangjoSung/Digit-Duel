# v0.4.13 — 화면과 게임 흐름 개선

출시일: 2026-10-03

- [개선] 시작 상점·배치에 공통 180초를 적용했습니다. 양쪽이 준비되면 바로 시작하고, 시간이 끝나면 부족한 말을 보충해 배치합니다.
- [개선] 메인 화면의 대표 하수인 TopBar·개인 시너지·말 정보를 정리했습니다. 능력치와 미해금 기술 소개를 함께 보고, 고정 말 정보 버튼으로 폭탄·함정도 확인합니다.
- [개선] 턴 상점을 시작 상점과 같은 구조로 바꾸고 구매 시간을 180초로 늘렸습니다. 하수인 등급별 테두리와 완료 후 대기 표시를 적용했습니다.
- [개선] 배틀에서 양쪽 전투원의 등급·HP·방어막·기본 능력치와 상태를 읽기 쉽게 정리했습니다. 기존 기술 설명을 재사용하고 중복 위력 표시를 없앴습니다.
- [개선] 싸우기·가방·포획·도망 화면에 내부 돌아가기를 통일했습니다. 가방은 아이템 타일, 포획은 조건과 볼 수량으로 표시합니다.
- [버그 수정] 재접속·포획·가방 대리 출전·전설 말판 아이콘에서 아트가 깨지는 경로를 수정했습니다.
- [버그 수정] 방장 나가기·끊김 시 승계, 즉시 강퇴, 참가자 재연결 대기와 방·결과 화면 핑을 수정했습니다.
- [밸런스] 수호자 3종의 구매가를 3코인으로 맞췄습니다.
