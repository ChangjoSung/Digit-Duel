# v0.4.0 — 온라인 PVP (2026-09-05)

같은 내부망에 있는 두 사람이 각자의 기기에서 대전할 수 있게 되었습니다.

## [기능 추가]

- 온라인 PVP — 각자의 기기에서 접속해 1:1 대전을 즐길 수 있습니다.
- 사전 배치 후 자동 매칭 — 로스터 선택과 배치를 먼저 끝내면 매칭 큐에 들어가고, 상대가 준비되는 순간 대전이 시작됩니다.
- 메뉴에서 서버 주소를 직접 입력하고 다음 실행 때 기억합니다.
- 서버를 실행하면 두 사람이 같은 주소에서 게임을 열 수 있습니다.

## [개선]

- 튜토리얼을 카드형 레이아웃으로 바꾸고 창 크기와 확대 배율에 따른 가독성을 개선했습니다.
- 보드 메모 기능과 HTML 데모 전반의 안정성을 다듬었습니다.

## 플레이

오프라인은 `demo/index.html`을 열면 됩니다. 온라인 대전은 한쪽 PC에서 `server/`의 릴레이 서버를 켜고, 두 사람이 그 서버 주소로 접속하면 자동으로 매칭됩니다. 이 서버는 내부망 대전용이며 인터넷 직접 공개는 지원하지 않습니다.
