# v0.4.7 — 출시 문서 정리 (hotfix)

**출시일: 2026-09-11** · [GitHub Release](https://github.com/ChangjoSung/Digit-Duel/releases/tag/v0.4.7) · [Issue #175](https://github.com/ChangjoSung/Digit-Duel/issues/175)

**게임 내용은 v0.4.6과 같습니다.** v0.4.6 출시 후에도 문서가 옛 상태로 남아 있던 것을 고친 문서 전용 hotfix 입니다.

## [수정]

- README 가 v0.4.6 출시 뒤에도 *"이 버전은 아직 릴리스가 없습니다 · 정식 버전은 v0.4.5"* 라고 표시하던 문제를 고쳤습니다.
- README 「새로운 기능」이 옛 v0.4.5 패치 노트를 먼저 보여 주던 순서를 바로잡고, 이전 버전과 같은 형식(배지 · 한 줄 요약 · 패치 노트 · 링크)으로 정리했습니다.
- v0.4.6 릴리스 노트에 들어가 있던 운영 사정 서술을 줄이고 이전 노트와 같은 구성으로 맞췄습니다.
- 게임 정보 표의 현재 버전·최근 업데이트 날짜, 검사 문서의 버전 표기를 v0.4.6 기준으로 갱신했습니다.

## 변경하지 않는 것

**게임 코드는 한 줄도 바뀌지 않았습니다** — `demo/index.html` · `roblox/` · `server/` 모두 v0.4.6 그대로입니다. 규칙 · 수치 · 화면 · 연출에 변화가 없으므로 **v0.4.6 을 이미 내려받으셨다면 다시 받으실 필요가 없습니다.**

## 플레이

v0.4.6 과 동일합니다. [v0.4.6 릴리스 노트](v0.4.6.md)의 플레이 방법을 참고하세요.
