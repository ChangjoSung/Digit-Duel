# v0.4.9 — 함정 아이콘 표시 수정

2026-09-11 · [Issue #201](https://github.com/ChangjoSung/Digit-Duel/issues/201)

함정 이모지를 지원하지 않는 환경에서 말판에 ‘함정’이라는 글자만 보이던 문제를 고쳤습니다. 폰트에 의존하지 않는 SVG 아이콘을 적용하고 README의 온라인 보드 사진을 다시 촬영했습니다. 게임 규칙과 비공개 상대 말의 표시 조건은 그대로입니다.

새 버전의 `demo/index.html`을 열거나 온라인 페이지를 새로고침하세요. 서버는 v0.4.8의 요청 처리 수정을 그대로 사용합니다. 이전 버전에서 갱신하는 운영자는 [서버 실행 안내](../../server/README.md)를 따르세요.
