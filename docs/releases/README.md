# 릴리스 노트

최신 정식 버전은 **[v0.4.5](v0.4.5.md)**입니다. [턴 행동·문서·튜토리얼 갱신](https://github.com/ChangjoSung/Digit-Duel/milestone/11)을 마치고 2026-09-08 CJ 플레이 QA PASS 및 배포 승인을 받았습니다.

다음 버전은 **[v0.4.6 — 수풀 탐색 개편·신규 공용 기술·연출 템포·전투 행동 정비·세로 화면](v0.4.6.md)**입니다. 마일스톤의 모든 이슈가 **2026-09-10 CJ 플레이 QA를 통과**했고 릴리스를 준비 중입니다. 아직 출시일·다운로드가 없어 아래 표에는 넣지 않습니다 — 이 표는 출시된 버전만 담습니다. 지금 내려받아 플레이하는 버전은 여전히 v0.4.5입니다.
