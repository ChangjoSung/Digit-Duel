# v0.4.1 — 온라인 안전 접속 (2026-09-06)

온라인 대전 서버가 기본적으로 외부에 열리지 않도록 바꾸고, 접속 코드 인증을 더했습니다.

## [기능 추가]

- 접속 코드 — 서버를 켤 때마다 새 코드가 만들어지고, 같은 코드를 입력한 사람끼리만 매칭됩니다. 코드는 브라우저 저장소 · 주소창 · 로그에 남지 않습니다.

## [개선]

- 릴레이 서버는 기본적으로 서버를 켠 PC 자신(`127.0.0.1`)에만 열립니다. 같은 공유기의 다른 PC와 대전하려면 `--lan` 또는 `DD_LAN=1`로 명시해야 합니다.
- 잘못된 접속과 비정상적인 요청을 차단하도록 서버 검사를 강화했습니다.
- 클라이언트는 안전한 주소 범위(localhost · 내부망 IP)로만 접속합니다. 파일을 직접 열었을 때는 메뉴에서 그 사실과 대안 주소를 안내합니다.

## [버그 수정]

- 재접속할 때 이전 연결의 콜백이 새 접속 상태를 덮어쓰던 문제를 수정했습니다.
