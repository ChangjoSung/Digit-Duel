# v0.4.5 — 턴 행동 정리 · 튜토리얼 갱신

**출시일: 2026-09-08** · [GitHub Release](https://github.com/ChangjoSung/Digit-Duel/releases/tag/v0.4.5) · [Milestone 11](https://github.com/ChangjoSung/Digit-Duel/milestone/11)

동료·왕끼리, 폭탄끼리 만나면 싸우는 대신 서로 한 칸씩 밀려나고, 텔레포트는 횟수 걱정 없이 쓰며, 도망친 뒤에는 보드에서 바로 후방 말을 고릅니다.

## [기능 추가]

- 텔레포트의 경기당 횟수 제한을 없앱니다. 사용 조건·주 행동 소모·취소·남은 전투 횟수 부족 시 사전 차단은 그대로입니다.
- 동료·왕끼리 접촉하면 포획 하수인이 있어도 싸우지 않고, 두 말이 접촉 방향의 반대쪽으로 한 칸씩 밀립니다. 폭탄이 폭탄·함정과 닿아도 제거·신규 정체 공개 없이 같은 방식으로 밀립니다. 이미 공개된 말은 다시 숨기지 않으며 왕 끝줄 도달의 공개·승리는 유지합니다.
- 밀고 나서도 두 말이 붙어 있거나 다른 상대 말과 닿아 있으면 "말 재배치!" 안내 뒤 두 말을 각자 자기 진영 → 자기 숲 → 중앙 광장 순으로 비어 있고 상대와 닿지 않는 칸에 함께 옮깁니다. 그런 칸이 없으면 현재 위치를 유지합니다. 왕이 밀려 상대 끝줄에 닿으면 즉시 승리합니다.
- 도망에 성공하면 보드에서 후방의 내 말을 골라 자리를 바꾸거나 생략하고, 이어서 전선의 말과 상대가 한 칸씩 밀립니다.

## [개선·수정]

- 평소 "주 행동 생략"·"턴 종료" 버튼을 없앱니다. 할 수 있는 주 행동이 없으면 자동으로 생략되고, 턴 시작부터 옆에 있던 적과의 선택 전투가 남았을 때만 "싸우지 않고 종료" 버튼이 나타납니다. 기권은 기존처럼 자기 턴에 가능합니다.
- 보드에 놓인 내 하수인·동료·왕 중 아직 회복 자세가 아닌 말은 HP가 가득 차도 지정할 수 있어 움직이지 않고 기다릴 수 있습니다.
- 함정의 자발 걷기 금지와 기존 텔레포트·도망 교환 허용은 유지하며, 새 밀기·재배치로도 옮겨집니다. 강제로 옮겨진 말을 "함정이 아니다"라고 추론하지 않습니다.
- 튜토리얼 10단계와 상황 도움말에서 텔레포트 "2번" 안내와 "턴 종료를 눌러요"를 새 규칙으로 바꾸고, v0.4.4의 다른 속성 공격기 교체 안내를 보완했습니다. README 캡처 10장도 검수한 커밋에서 다시 만들었습니다.

## 변경하지 않는 것

전투 턴당 2회, 회복 해제 조건, 왕 불가침, 버닝 타임 이동 규칙, 폭탄 직접 접촉(하수인·동료·왕), 함정 발동 공개, 6라운드 HP 비율 판정, 전투 4메뉴, 상성·상태 확률·공격형 수치. 수풀 탐색 전면 점검은 이번 범위가 아닙니다. 출시 당시 v0.4.6 예정이었으나, 2026-09-09 CJ 일정 변경으로 [v0.4.7](https://github.com/ChangjoSung/Digit-Duel/milestone/13)에서 진행할 예정입니다(Roblox 포팅은 v0.4.6).
