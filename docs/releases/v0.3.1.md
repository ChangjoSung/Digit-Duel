# v0.3.1 — 온보딩 튜토리얼 (2026-09-03)

처음 켠 사람이 규칙을 배우고, 상대의 숨은 말을 추리한 내용을 판 위에 기록할 수 있게 되었습니다.

## [기능 추가]

- 승리 조건부터 버닝 타임까지 그림으로 설명하는 10단계 튜토리얼. 첫 실행 때 자동으로 열리고, 다시 보기 · 건너뛰기 · 키보드 조작 · 상황별 도움말을 지원합니다.
- 추측 메모 — 상대의 미공개 말에 왕 · 동료 · 속성 하수인 · 폭탄 · 함정 8종으로 추측을 남깁니다. 반투명 표시와 점선 테두리로 실제 공개 말과 구별됩니다.

## [개선]

- 튜토리얼 팝업을 PC 640px · 대형 PC 760px로 넓히고 그림을 전체 폭으로 표시합니다.
- 데스크톱 · 모바일에서 튜토리얼 글자가 잘리거나 간격이 어긋나던 문제를 보정했습니다.
