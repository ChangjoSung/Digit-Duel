# v0.4.15 — 배틀 스텟 표시·설명과 등급 성장 개선

출시일: 2026-10-05

- [개선] 배틀의 여섯째 스텟에 시너지와 하수인 가산을 반영한 **왕국 효과 발동률**을 표시합니다. 표시와 실제 판정이 같은 계산식을 사용합니다.
- [개선] 상성표 왼쪽의 스텟 버튼에서 공격력·방어력·속도·회피·치명타·왕국 효과의 짧은 설명을 확인합니다.
- [밸런스] 일반 하수인의 1성 대비 HP는 **100·135·175·225%**, 공격력은 **100·125·155·190%**로 성장합니다. 전설은 대응 4성의 HP·공격력보다 20% 높게 조정했습니다.
- [수정] 하수인 정보 창의 폭탄·함정 설명을 실제 이동·발동·효과에 맞게 고쳤습니다.
