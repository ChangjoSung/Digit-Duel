# v0.3.0 — HTML 프로토타입 (2026-09-02)

Digit-Duel의 첫 공식 릴리스입니다. 브라우저로 여는 HTML 파일 하나로 게임 전체를 플레이할 수 있습니다.

## [기능 추가]

- 7열 × 13행 판 위에서 정체를 숨긴 말 14개로 겨루는 1대1 턴제 전략 보드게임.
- 게임 모드 4종 — PVE 5급 · PVE 5단 · PVP 핫시트 2인 · AI vs AI 관전.
- 숲 은폐 · 흔적 탐색 · 포획 · 도망 · 텔레포트 · 버닝 타임.
- 하수인 20종 로스터와 기술 4슬롯 체계, 경기마다 6종 선택.
- 플레이어별 · 합산 지표를 함께 보여주는 지표 패널.

## 플레이

저장소를 내려받아 `demo/index.html`을 브라우저로 열면 바로 실행됩니다. 설치도 서버도 필요 없습니다.
