# v0.4.11 — 전투·경제·계정·경기 UI 개편

2026-09-29

- [기능 추가] 로그인 ID·닉네임·이메일로 계정을 만들고, 등록 이메일의 6자리 코드로 비밀번호를 재설정합니다. 로비에서 공식 승·패와 최근 20경기, 대표 하수인을 확인할 수 있습니다.
- [기능 추가] 공개 방에 이름·검색·참가 상태·실측 핑을 더했습니다. 상대와 주고받는 이모티콘 6종도 추가했습니다.
- [기능 추가] 일반 하수인 30종과 전설 3종, 왕·동료 스킬, 불·풀·땅·번개·물 5속성, 왕국·아키타입 시너지를 적용했습니다.
- [기능 추가] 6칸 시작·정기 상점, 하수인 성장·교체, 가방 3칸과 전투 포획으로 경기 중 전력을 바꿀 수 있습니다.
- [개선] 전투 능력치·피해·상태이상·방어막·행동 순서를 정비했습니다. 전투 후에는 HP를 보존하고 다른 전투 상태와 쿨타임을 초기화합니다.
- [개선] 서버가 거래와 경기 결과를 판정합니다. 배치 90초·보드 행동 30초·전투 행동 60초를 관리하고, 연결이 끊긴 동안 타이머를 멈춥니다.
- [개선] 타이틀·로비·공개 방·상점·배치·전략 보드·전투·결과 화면과 게임 아트를 새 구성으로 정리했습니다.
- [개선] Windows용 LAN HTTPS 실행기를 하나로 정리했습니다. 공개 웹 플레이에는 별도 설치가 필요하지 않습니다.

[바로 플레이](https://digit-duel-mipa.onrender.com)에서 두 사람이 각각 가입·로그인한 뒤 공개 방을 만들고 참가하세요. 현재 싱글플레이·Google 로그인·로비 상점·채팅은 잠겨 있습니다. 서버가 재시작되면 진행 중인 경기는 복구되지 않으며 확정된 계정·전적은 남습니다.
