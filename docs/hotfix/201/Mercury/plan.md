# #201 온라인 1vs1 아트 누락 hotfix

2026-09-11 · CJ 요청. 현재 출시 v0.4.7의 main `ff6e87a0c028ae39725d5bb5971052a84410f328`에서 분기했다. Unity checkout의 파일과 사용자 작업을 보존하기 위해 별도 Orca checkout `hotfix-201-online-art`를 사용하며 Git 브랜치는 `hotfix/201-online-art`다.

첨부 화면은 P2·17턴이다. 왕·동료가 이모지로, 하수인 일부가 이름으로 표시되는 현상을 신고했다. 상대 미공개 말의 물음표, 폭탄·함정의 기존 기호는 정상 정보 경계와 구분한다. 관측만으로 이미지 파일 유실이나 서버 문제라고 단정하지 않는다.

## 확인할 경로

- 파일 직접 열기와 실제 LAN/HTTP 서버의 아트 요청·응답 차이.
- 20종 하수인40개 + 왕/동료4개 프리로드, 후속 보드·전투 렌더 요청과 HTTP 요청 한도.
- 온라인 양쪽 플레이어의 실제 보드·전투 이미지와 로드 실패 처리.
- 공개되지 않은 상대 정체가 DOM·요청 패턴에 새로 드러나지 않는지, 게임 규칙·RNG·프로토콜이 유지되는지.

## 역할과 납품

Mars는 Client 분석·구현, 서버 실행 경로가 원인이면 Jupiter가 수정한다. Saturn은 파일을 쓰지 않는 독립 검수이며 증거를 Mercury가 보관한다. Git/GitHub/Notion·패치 릴리스는 Mercury가 담당한다. 각 구현은 같은 Issue201과 main hotfix PR로 통합한다.

현재 최신 릴리스 v0.4.7을 확인했다. 수정·독립 검수·필수 CI 후 v0.4.8 패치 릴리스로 내보내고 main→dev→활성 Roblox/Unity 트랙 순서로 동기화한다. main/dev/Roblox 기존 CI6, Unity CI7·strict·관리자 보호를 유지한다. 보호 브랜치에 직접 커밋하지 않는다.

원인·실행 명령·old/new 대조·브라우저 증거·rollback은 구현 완료 후 결과 문서로 정리한다. [Issue201](https://github.com/ChangjoSung/Digit-Duel/issues/201)이 상태 원본이다.

2026-09-11 CJ 추가 지시: 아트 정상화 확인 후 README의 기존 아트 미표시 플레이 사진도 교체한다. 같은 Issue201의 납품 범위이며, 최종 소스로 실제 브라우저에서 보드·전투를 촬영하고 이미지/소스 지문을 확인한 뒤 Mercury가 갤러리 경로·캡션을 갱신한다. 사진은 안내/전환 효과에 가리지 않아야 하며, 인위적으로 구성한 검증 장면이면 보고서에 구분한다.
