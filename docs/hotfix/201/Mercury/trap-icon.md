# #201 함정 아이콘 후속 보완

2026-09-11 · CJ 지시. v0.4.8의 실제 README 보드에서 함정이 글자로 남은 것을 후속 보완한다. 기존 함정은 🪤 이모지를 그릴 수 없으면 같은 뜻의 글자로 대체했으며, 이번에는 알려진 함정을 폰트 독립 SVG로 표현한다. 상대 미공개 말은 기존 물음표·플레이어가 남긴 추측 메모 정책을 유지한다. 게임 규칙·RNG·서버·기존 왕/동료/하수인 복구는 변경 대상이 아니다.

같은 [Issue201](https://github.com/ChangjoSung/Digit-Duel/issues/201)을 유지하고 `main`의 v0.4.8 `b569ebb`에서 `hotfix/201-trap-icon`을 분기했다. CJ가 전용 아이콘 직접 제작까지 명시해 Earth가 원본 SVG를 제작하고 Mars가 HTML 렌더·회귀·실제 보드 촬영을 담당한다. Saturn은 파일을 쓰지 않는 독립 검수, Mercury는 README·Git·출시·문서를 담당한다. 보고·검증·README를 한 제품 PR에 묶고 중간 커밋은 squash한다.

## 이력 관리

이미 배포한 태그를 옮기면 같은 버전 번호가 서로 다른 바이트를 가리키므로 v0.4.8은 보존한다. 이번 코드 변경의 즉시 배포 버전은 다음 패치 v0.4.9다. 일반적으로 패치마다 개별 화면을 급히 출시하는 대신 최종 화면 검수와 추가 수정사항을 한 배포에 모으면 버전 증가를 줄일 수 있다. 기존 저장소의 필수 PR/CI·dev 역병합·활성 트랙 동기화는 유지한다. 버전 번호를 숨기거나 공유 이력을 force-push로 지워 이력을 줄이지 않는다.

출시 이력만 확인하려면 `git log --first-parent --oneline origin/main`을 사용한다. 모든 트랙의 그래프를 한꺼번에 보는 것보다 출시 흐름이 분명하다. 원격을 갱신한 뒤 통합 대상 기준의 임시 브랜치를 만들고 한 번만 merge해, strict 보호에서 불가능한 PR이나 중복 로컬 merge를 만들지 않는다.

## 검증·납품

실제 Chrome 두 탭이 테스트 전용 서버의 인증·온라인 매칭·배치를 거친 [촬영 기록](../Mars/trap-icon/report.json)은 38/38 PASS다. 이 PC에서는 함정 이모지 지원 측정값이 false인데도 두 진영의 함정 2개씩이 SVG로 보였다. CSS 크기32px와 보드 축소 후29/30px를 구분하고 하수인 아이콘과 동일한 크기를 확인했다. 상대14말은 모두 물음표이고 함정 SVG·정체 속성·자산 경로가 없었다. 두 클라이언트 각각 자산50요청 모두200, 새 SVG 요청0이다. 같은 PC의 두 탭 검증이며 두 실기기의 LAN 장기 플레이를 검증했다고 주장하지 않는다.

Saturn과 Mercury가 최종 P1/P2 사진을 직접 확인했다. README는 새 P1 보드(v0.4.9), 기존 오프라인 전투(v0.4.8), 역사적 튜토리얼(v0.4.6)을 구분한다. 소스 SHA256은 `cc82867b3abc4b578009def2adbc88d5b3f5600e1f91970a2479b716d1d6e70d`, 줄바꿈 정규화 후 Git blob은 `460ea088446f133524a76e17e6776d02cb280360`이다. SVG/P1/P2 SHA256은 촬영 기록과 대조했다. 이전 v0.4.8 PASS는 새 보완의 검증으로 사용하지 않는다. 최신 PR·CI·릴리스·동기화 SHA와 CJ 확인은 [Issue201](https://github.com/ChangjoSung/Digit-Duel/issues/201)을 원본으로 한다.

검수 중 기존 이모지 전용 단언을 SVG 계약으로 바꿨고, 새 검사에서 빈 DOM 필드를 읽던 부분·숲이 아닌 배치·좌표만 비교하던 부분도 보완 대상으로 식별했다. 첫 브라우저34/2는 보드 축소를 무시한 크기 단언 오류였으며, 제품을 바꾸지 않고 CSS/실제 크기 비교를 고친 뒤38/0을 얻었다. Mars의 큐 메시지 미확인으로 QA 수정 전달이 지연돼 Mercury가 소유 터미널을 중단·안내했고 불필요한 전체 검사 반복도 중단했다. 이 초기 결과들을 최종 PASS로 소급하지 않는다.

Run run_9dad5eea7542: Mars task_dd3f55ddb519/ctx_8f0a2345bcc3, Earth task_92749b19ae3e/ctx_129ef8f42e7e. Earth 자산과 Mars 코드의 소유 범위를 분리했으며 같은 Issue·제품 PR에 통합한다.

Earth 원본 납품 수락: msg_c716e5a8b640, 허용 파일2개(SVG와 provenance)만 수정했다. 32×32 viewBox·path/circle·외부 의존 없음의 원본이고 실제 게임 렌더 판정은 Mars 촬영·Saturn 검수로 분리한다. [자산 기록](../Earth/trap-icon.md)을 보관하고 완료 Worker를 release한다.

표시 범위는 보드·배치·플레이어의 추측 메모 공통 glyphSpan 경로다. 튜토리얼의 역사적 설명 그림과 함정 발동 효과의 장식 이모지는 이번 보드 아이콘 수정에서 변경하지 않는다. 새 SVG는 원본을 같은 viewBox로 인라인 사용하며 외부 요청을 늘리지 않는다. Saturn task_883116b500a7/ctx_75b589fd8d8e는 독립 READ_ONLY 검수다.

## 적용·되돌리기

새 버전의 HTML을 열거나 온라인 페이지를 새로고침한다. 운영 중인 서버를 이 작업에서 강제로 재시작하지 않았다. 서버는 v0.4.8 아트 요청 수정과 같으며, 운영자가 갱신할 때 [서버 안내](../../../../server/README.md)를 따른다. 문제 발생 시 v0.4.8 배포본으로 되돌릴 수 있다(함정의 기존 글자 폴백도 복귀). 공유 태그를 이동하거나 보호 브랜치를 강제로 덮어쓰지 않는다.
