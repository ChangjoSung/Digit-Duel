## 객관적 판단과 한계

- **아트:** 승인된 기존100자산으로 해결했다. 새 제작 없이 정체 정보를 전투 그림에 연결한 수정이다.
- **공격형:** 같은 조건 AI 모형에서 전체 판 후공−선공 격차는14.2→5.2%p, 도망 제외 결판은14.9→10.1%p로 줄었다. 그러나 비미러 결판은3.5→7.1%p, 불 속성은17.4→18.2%p로 증가했다. 전체 개선의 상당 부분은 공격형 미러 대진에서 발생했다. 모든 상성의 균형 개선이나 사람 체감 해결로 결론 내릴 수 없다. 불 고위력+결정타 합계는97→88이지만 피해 변동 상단106으로 HP100 제거 가능성도 남는다.
- **감전:** #95가 양쪽에 들어간 동일 기준 비교에서 일반 감전1000회×5시드 구간은46.9~51.0%. 화상·약화 결과 벡터와 확정 감전 이후 난수는 같았다. AI40판 전투당 감전0.179→0.139는 표본 추정치이며 사람 승률 보장이 아니다.
- **기술 교체:** 약상성에 대응할 선택지를 추가한다. 공격기 두 개를 모두 타 속성으로 바꿀 수 있지만 본체의 방어 약점은 남고, 교체로 쿨을 초기화할 수 없다. 전투 AI는 기술 속성을 반영한다. 보드 단계 전투 추정은 본체 속성 근사를 유지하며 자기 습득 기술까지 반영하는 확대는 별도 기획 대상이다.
- **검증 범위:** 실제 Chrome 두 클라이언트·루프백 릴레이와 고정된 위치/시드 fixture로 동기화·클릭 경로를 확인한다. 실제 서로 다른 기기의 LAN 대전, 모바일·비Chrome·wss, 사람 조합별 밸런스는 확인하지 않았다. 온라인 비권위 lockstep의 기존 상대 데이터 메모리 보유 구조는 유지하며, 새 DOM·이미지·접근성·로그 노출 방지가 이번 정보 경계다.
