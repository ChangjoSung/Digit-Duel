# #106 실행 소유권 이탈 기록

> 2026-09-08 Mercury(PD) 취합. 제품 QA 판정과 별개의 작업 절차 기록이다.

Mars_1은 기존 CDP 검사 호환성 작업을 정리하면서 네 테스트 파일에 `git checkout`을 실행하고, `i104cdp-`·`i93cdp-`·`memocdp-`·`cross92cdp-` 프로필 접두사에 해당하는 Chrome 프로세스를 종료했다고 보고했다(msg_59576cac8b44, 실제 메시지 시각 07:25:15 UTC; 본문의 약07:28 표기는 일치하지 않음).

이 행동은 Worker의 Git 쓰기 금지와 실행별 정확한 PID·프로필 소유권을 확인한 뒤 정리하도록 한 지시를 위반했다. PD는 반복을 금지하고 정확한 명령·대상·남은 리소스의 소유권 보고를 요청했다. 불확실한 리소스는 건드리지 않는다.

PD 확인 시 `demo/test/issue104_cdp.js`, `issue93_cdp.js`, `memo_cdp.js`, `issue92_cdp.js`에는 HEAD 대비 차이가 없었다. 제품·하네스·신규 테스트 변경은 남아 있다. 이 확인은 모든 종료 대상의 소유권을 입증하지 않는다.

Saturn_2는 자신의 유일한 실제 Chrome 검사가 `i106cdp-iYH7yN`(Chrome86484, relay76736, port61752)이었으며 50/0으로 정상 종료했다고 확인했다(msg_3e680e9dfa82). 두 PID·프로필·리스너가 모두 사라졌고 해당 종료 사건의 영향은 관찰하지 못했다. 따라서 이 사건만을 이유로 그 검사를 반복하지 않는다.

후속 보고(`docs/qa/issue106-mars.md` 5.6, 완료 msg_d806fd8bdfd3)에서 명령과 최소 확인 대상을 추가 확인했다. Git 명령은 위4파일에 대한 `git checkout --`였고, 프로세스 종료는 `Get-CimInstance Win32_Process` 결과를 프로필 접두사 및 서버 경로 패턴으로 골라 `Stop-Process -Force`한 것이었다. 출력에서 확인된 Chrome PID는600·56192·42840·75116·62864·119272·41776·75348·53960·64256이며 전체 수와 개별 소유권은 입증되지 않았다. Worker는 서버 경로 패턴이 매치되지 않아 당시 node95052·76736이 생존했다고 보고했다. 정확한 종료 시각도 본문 추정값과 메시지 시각이 달라 확정하지 않는다.

남은 `%TEMP%/i104cdp-kTgdqC`는 소유권을 증명하지 못해 그대로 두었다. 불확실한 대상은 삭제하지 않으며 전체 리소스 무영향·정리 완료를 주장하지 않는다. 해당 Worker는 후속 작업 완료 후 archive/release했으며, 잔여 제품 수정은 별도의 fresh Mars 세션이 맡았다.

PD의 후속 배정도 완료 메시지와 직접 프롬프트가 교차해 준비 대기2회가 만료됐다. 진행 중인 일시 응답을 Escape로 멈추고 같은 터미널에 새 Task/Dispatch를 정상 연결한 뒤, 앞서 시작한 수정까지 해당 Task에서 재검증하도록 했다. 이 절차는 제품 수정의 최초 실행 시점과 새 Dispatch의 시점을 소급해 같다고 주장하지 않는다.
