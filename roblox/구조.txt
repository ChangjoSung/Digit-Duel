일반 2인 대전
1. 2명이 앉으면 시작버튼 활성화 F키로 시작
2. 화면에 보드게임 창이 뜨며(이때는 이동 불가) 해당 창 왼쪽에는 보드게임판이 오른쪽에는 배치가능한 말들을 선택 할 수 있음
3. 배치를 규칙에따라 전부 완료하면 배치 완료버튼 활성화 두명 모두 활성화 하면 자동게임 시작
4. 배치 완료버튼 옆에는 나가기 버튼이 있음 그 나가기 버튼을 눌러야만 창이 닫히며 이동 가능
5. 전투와 같은 부분들은 또 새로운 창이 뜸 (웹 버전 참고)

1인 대전(AI대전)

1. 1명이 앉고 B버튼으로 ai모드 시작
2. 화면에 보드게임 창이 뜨며(이때는 이동 불가) 해당 창 왼쪽에는 보드게임판이 오른쪽에는 배치가능한 말들을 선택 할 수 있음
3. 배치를 규칙에따라 전부 완료하면 배치 완료버튼 활성화 봇은 말 자동 선택 및 자동 배치기 때문에 1명만 완료 버튼 누르면 됨
4. 나머지는 2인 대전과 같음
